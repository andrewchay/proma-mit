# 企业工作区成员存储首片

成员表以现有 Postgres 工作区的 `(tenant_id, user_id, workspace_slug)` 作为外键；成员身份包含租户、工作区所有者、工作区名与成员用户 ID。所有者由已有工作区的 `user_id` 确定；目前仅登记 editor/viewer，不能通过成员记录转移所有权。删除工作区时其成员记录由数据库级联删除。

独立 Postgres 测试覆盖跨连接实例持久化、同名工作区的租户和所有者隔离、非所有者不能替其他所有者写入、成员撤销和非法角色。`/agent/workspaces/{slug}/members` 提供所有者自己的成员登记读取及逐个设置/移除；写入需要现有 operator/admin 角色，Cookie 会话还需同源请求。API 明确返回 `sharedAccessEnabled: false`；用户 ID 仅作为登记，不发送邀请或验证外部账号。

此接口依赖现有已认证 scope，尚未连接邀请流程或 Runtime 权限判断，**登记成员尚不会授予共享工作区访问权**。现有按用户隔离的工作区、会话、凭证和对象存储未迁移；已有工作区需要预先存在。

## 显式发布单个只读成果

所有者可对已有工作区文件提交预期 SHA-256 并明确发布，当前登记的成员才能通过只读下载接口获取该文件。未发布的文件默认不可读；读取时重新检查成员和发布记录，并核对实际字节的哈希和长度，内容变化后返回冲突，需所有者重新核对发布。所有者可撤销发布；成员撤权在对象读取期间也会再次检查。下载使用 attachment 和 no-store，避免将 HTML 作为页面直接运行。成员登记响应中的 sharedAccessEnabled: false 仍表示没有开放整个工作区或 Runtime。

真实 Postgres 测试使用内存对象存储，覆盖跨租户与非成员隔离、路径穿越、内容变化、重发布、撤销以及读取过程中的撤权；尚未验证真实 S3、生产身份提供方或桌面/Web 界面。发布记录没有历史版本或不可变快照；已下载字节无法收回，最终权限检查之后仍存在响应在途窗口。共享文件发布和下载使用分块有界读取；限制按实际接收字节执行，超限取消流并在下载时再次确认成员权限。普通工作区文件的其他读取路径不在本片范围。真实 S3 生产服务尚未验收；本地测试使用真实 S3 SDK 与模拟 HTTP 端点。

## 发现已发布成果

所有者与当前登记成员可以分页读取明确发布的文件清单，包括相对路径、内容 hash、大小及发布时间；未发布文件不出现在列表中。每次分页都重新查询当前工作区和成员授权，跨租户、非成员或撤权后返回不可访问；列表不授予工作区和 Runtime 权限。真实 Postgres 测试覆盖空列表、成员隔离、撤权和 101 条分页；目前仅提供服务端 API，尚无成员邀请、Web 界面或生产部署验收。


## Web 共享成果入口

Web 控制台支持输入所有者 ID 和工作区，分页读取已发布成果并按用户点击下载；修改身份、工作区或连接会清除旧列表，加载失败或权限失效也会清除。浏览器测试使用模拟 HTTP 响应验证分页、下载及撤权后的显示；实际权限仍由服务端每次校验。该测试不代表真实身份提供方、对象存储或生产部署验收。

审计与用量 CSV 将疑似公式开头的文本字段加单引号前缀，降低被表格软件作为公式执行的风险；数值保持数值表示，JSON 导出保留原值。自动化测试覆盖公式前缀、控制字符、引号和 JSON 保真；未逐一验证所有表格软件的导入行为。

工作区文件上传按实际读取字节限流，超限取消并在写入对象存储之前返回 413；临时 PostgreSQL 与内存对象存储的端到端测试覆盖伪造较小 Content-Length、超限保留原文件与恰好达到上限。该测试不代表生产 S3 验收；内置 S3 所有者下载已支持流式返回；未实现流接口的自定义存储仍使用原兼容路径。

Web 所有者可输入工作区与相对路径，先读取文件并查看大小、SHA-256、有限文本预览或下载完整内容，再主动确认发布；路径或连接变化清除待发布内容，服务端哈希冲突要求重新读取。浏览器测试使用模拟服务覆盖明确确认、路径变更及冲突；界面核对限制为 10 MB，生产 S3、组织身份与用户验收尚未验证。

Web 所有者可以读取成员、登记只读成员和撤销成员；登记对已发布成果生效，不开放整个工作区或 Runtime。新增使用服务端 `createOnly` 原子条件，成员已存在时返回冲突而不覆盖原角色；临时 PostgreSQL 测试验证角色不被覆盖，浏览器测试使用模拟服务验证界面动作。成员身份目录、邀请和真实组织身份验证尚未接入。

所有者可分页查看并撤销已发布成果；每次发布分配独立版本 ID，界面发送所见版本 ID，若已被重新发布则返回冲突并要求刷新。成员读取在对象读取前后同时核对版本 ID，防止读取期间撤销或重新发布后沿用旧授权。临时 PostgreSQL 测试覆盖相同内容重新发布后的旧版本撤销，另在隔离旧表上验证字段迁移与原记录保留；浏览器测试使用模拟服务。旧服务实例不生成新的版本 ID，混合新旧实例滚动部署期间不能保证这一版本检查，需统一升级后验收。

本地浏览器端到端测试使用临时 PostgreSQL、内存对象存储及本地 HTTP 服务，串联成员登记、文件核对发布、成员下载并核对字节、按版本撤销和成员重新查看；身份使用测试替身。临时数据库容器已清理，真实身份提供方、生产对象存储和客户验收仍未覆盖。

内置 S3 所有者文件下载可在对象完整到达前输出首块，避免服务端预先加载整个对象；临时 S3 兼容 HTTP 替身验证分块，PostgreSQL 与内存存储测试验证大于当前上传限额的旧对象仍可下载。真实 S3 和自定义存储的流式行为尚未验收。
