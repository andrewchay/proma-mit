# 企业工作区成员存储首片

成员表以现有 Postgres 工作区的 `(tenant_id, user_id, workspace_slug)` 作为外键；成员身份包含租户、工作区所有者、工作区名与成员用户 ID。所有者由已有工作区的 `user_id` 确定；目前仅登记 editor/viewer，不能通过成员记录转移所有权。删除工作区时其成员记录由数据库级联删除。

独立 Postgres 测试覆盖跨连接实例持久化、同名工作区的租户和所有者隔离、非所有者不能替其他所有者写入、成员撤销和非法角色。调用方必须传入已认证的用户 scope；本片没有连接成员 API、邀请流程或 Runtime 权限判断，**登记成员尚不会授予共享工作区访问权**。现有按用户隔离的工作区、会话、凭证和对象存储未迁移。
