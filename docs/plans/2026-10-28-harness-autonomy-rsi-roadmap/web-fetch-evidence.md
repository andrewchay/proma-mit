# WebFetch 有界响应

WebFetch 对实际接收的响应流执行 2,000,000 字节限制，超限时取消流，不依赖 Content-Length。原有 15 秒超时现在覆盖响应体读取；调用方会话取消信号也会取消正在读取的响应体。HTTP 错误的响应体不会继续读取。测试使用临时项目数据库和模拟 fetch，覆盖正常 HTML/JSON、流超限、调用方取消及 HTTP 失败；没有访问真实外部网站。

本片不改变 WebFetch 的 HTTP(S) 目标与重定向策略，不证明服务端网络隔离、远端副作用的停止或真实 Provider 行为；Agent 会话被取消不代表远端服务已撤销处理。WebSearch 与其他网络工具的响应大小和超时边界需分别检查。
