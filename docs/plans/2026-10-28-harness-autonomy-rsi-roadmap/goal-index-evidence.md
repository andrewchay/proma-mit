# Goal 索引损坏时保留数据

`goals.json` 仅在文件确实不存在时视为空索引。JSON 损坏、格式错误、Goal 缺少身份、ID 重复、不可读路径或符号链接均返回错误，后续创建、更新和删除不会以空索引覆盖原文件。索引临时文件使用随机名称与独占创建，Goal ID 限制为安全文件名；既有 JSONL 事件不被修改；损坏索引不自动重建，需基于保留文件和事件单独恢复。

定向测试覆盖损坏内容、格式错误、重复 ID、悬空和有效符号链接、临时文件链接、非法 ID、首次启动以及创建/删除不覆盖原数据；保留对正常旧 Goal 字段的兼容，只校验索引与身份的最小结构。该切片不解决索引与 JSONL 的跨文件原子性、进程并发写入和权限故障，也不宣称已有自动恢复或打包应用验收。
