# 设计系统上下文的缺项与刷新

声明需要设计系统的 Skill 在工作区没有可用 `DESIGN.md` 时，会把缺项提示注入设计上下文，要求执行者告知用户且不声称品牌合规。此提示经现有上下文组合器供 Agent Runtime 使用；它不构成独立的品牌合规检查或界面告警。

临时工作区测试验证同一会话再次读取 Skill 时重新读取更新后的 `DESIGN.md` 与 `tokens.css`，不会复用旧品牌正文；自动化测试未覆盖真实 Provider 的遵循情况或企业品牌资产审批。

## 设计成果选区与反馈

Owner 交付卡可在成果正文选择最多 300 字，或在隔离的 HTML 静态预览中点击含文字的元素，明确选择将片段带入 Owner 修改意见。意见复用已有消息引用，绑定消息 ID、成果 hash 和步骤；选中本身不会发送消息、修改成果或启动执行。

静态预览在 opaque origin 的 sandbox iframe 运行专用选区脚本；预览副本删除成果脚本、嵌套 frame、base 及 http-equiv 元数据，以 CSP 禁止成果脚本与外部资源。宿主只接受当前 iframe、当前随机版本令牌和有限字段的消息，选区内容仍当作不可信文本显示，需用户主动确认使用。浏览器测试覆盖成果脚本不运行、外部资源被拒绝、点击选区与伪造消息；尚未证明全部复杂 HTML、动态交互、打包 Electron 或真实 Provider 场景。下载的原始 HTML 保持原样，用户在浏览器打开时其脚本行为由浏览器环境决定。

选区现已支持图片、SVG 和 canvas：引用显示无障碍描述或“无文字描述”，附带有限层级的预览 DOM 位置供人工定位。这个位置是提示，不保证唯一或能稳定映射到源文件；不会上传图片、读取外部资源，也不会自动修改元素。

## 设计任务草稿

项目 Owner 对话提供网页、报告、幻灯片和海报的设计任务草稿，可填写目标与可选品牌或风格参考；添加时保留已有对话内容，由用户检查后主动发送。此入口不安装品牌资源、不覆盖工作区文件，也不声称设计已符合所选品牌；缺失资源时要求明确说明。浏览器测试覆盖类型、风格、保留已有草稿及不自动发送，尚未验证真实 Provider 生成或品牌资源选择与版本管理。

## 品牌参考目录

设计任务草稿可从内置 OpenDesign 索引选择 152 个品牌/设计系统名称，或补充自定义风格要求；选择后只加入待发送的文本草稿，不下载、安装或激活设计规范。目录不含品牌图形资产，来源及 Apache-2.0 许可记录在生成文件内；可执行 `bun scripts/generate-design-catalog.ts` 从已随包提供的索引重新生成。测试核对生成目录与来源一致，并在浏览器验证选择及不自动发送。品牌资源的实际获取、版本锁定和审批仍待完成。


## 本地设计参考预览

设计任务草稿选择品牌后可以只读查看随应用打包的 DESIGN.md 与 tokens.css；内容来自 OpenDesign 固定版本的整理资料，不代表品牌官方授权。首次选择时按需加载，切换时丢弃过期加载结果。查看不会写入工作区、自动发送或注入 Agent，品牌合规、企业审批与真实 Provider 效果仍需另行验证。可通过 `bun scripts/generate-design-reference-bundle.ts <OpenDesign 仓库路径>` 从同版本且相关文件无修改的检出重建；包中附带 Apache-2.0 许可证。

设计参考支持用户选中说明或令牌中的片段（最多 1600 字），可编辑后加入对话草稿，附来源版本与“非完整规范”标记；切换品牌清除已选片段。用户需检查草稿并主动发送，不能据此宣称完整规范已注入或品牌合规。浏览器测试覆盖选中引用、切换品牌及不自动发送。
