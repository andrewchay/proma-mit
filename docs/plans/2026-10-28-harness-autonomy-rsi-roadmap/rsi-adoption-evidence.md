# RSI 候选审批的证据复核

能力候选创建时已有脱敏和样本数检查。批准执行时再次检查至少三条不重复的证据引用仍属于该员工、仍已脱敏且未排除；工作区候选还须匹配冻结工作区。证据删除、排除或缺失时记录执行失败，不激活能力。旧审批若没有证据引用，需要重新生成候选，不补造历史证据。

候选还冻结样本身份、脱敏摘要、执行结果和最新人工判断的 SHA-256 摘要；审批时如证据内容或判断发生变化则拒绝激活。旧候选缺少摘要时需重新生成。定向测试覆盖合法候选、等待审批期间排除或修改样本、缺少引用的旧审批。摘要不是防本地文件篡改的签名，也不证明评测独立性或真实用户认可能力提升。

证据、员工状态和工作区范围在能力版本激活的 SQLite 事务内再次核验；验证失败会回滚整个事务。现有测试验证同连接事务回滚，尚未单独完成跨进程竞争与真实用户验收。

## held-out 完整性

自演化评测循环要求训练集基线和候选 case 完整；启用 held-out 时也必须取得基线与候选的完整 case 集和有限的有效分数；缺失、重复、异常或任一 case 失败时回滚候选，不把缺失分数写成零或声明门禁通过。已持久化的历史记录不回填、不改写；旧分数仍需独立核查来源。员工评测服务对缺失 held-out 总分返回 `held_out_unavailable`，不会创建推广审批。定向测试覆盖真实评测循环中的训练/held-out 基线和候选缺失、模拟 Provider 失败，以及服务决策函数；独立 runBaseline 也在任一训练或 held-out 调用失败时停止并不落盘，训练与 held-out 重叠时在调用模型前拒绝。历史 scoreboard 未改变。尚未完成真实 Provider 和独立评判验收。

## 评判来源与失败

指定模型或注入评判函数后，返回空值、异常、非有限或越界分数均标记该次评测失败，不能静默回退规则分并记录为模型评判；预算耗尽亦如此。仅未指定评判函数时使用规则评分。相同模型标识即使配置了不同渠道也不视为模型区分；注入函数的真实来源无法从配置推断，规则和注入评分不声明独立。界面与审批摘要将原有独立标记表述为配置声明，并明确独立性未经核验；历史记录未改写、仍需审计。不同模型标识也不能证明实际模型或评判流程独立，真实 Provider 与业务验收仍未验证。

## 人工判断来源

学习样本的人工判断投影先定位同一交付与执行的最新验收事件，再要求事件来自本机公共人工入口 `local-user` 且符合当时 reviewer。更新的自动验收或其他尚无可验证人工来源的事件会使该样本的当前人工判断为空，不回退到旧判断；原始事件和样本保留。多用户的认证来源尚未接入此投影，不能仅凭身份目录名称认定为人工。

## 重复运行的基线观测

自演化每次都执行新的基线评测；此前仅以 Agent 版本查重，相同版本的后续真实结果不会写入 scoreboard。现改为每次训练案例完整后追加本次结果，保留相同版本的多次观测；测试以同版本两次不同分数验证两条记录均可读取，并回归 held-out 与命令路径。旧记录未修改或补造，历史基准与评分规则版本来源仍需独立核验；JSON 存储的跨进程并发写入、Provider 行为和人工验收不在此切片验证范围。

## 候选记录失败时的回滚状态

候选通过评测后，scoreboard 写入抛错原本会进入回滚，但此前已将该轮标为 accepted，造成“已接受且已回滚”的矛盾状态。现将接受标记放在写入成功后；测试通过让临时写入路径不可写来验证回滚、基线版本与分数保留、候选未记为接受。此证据不保证进程崩溃时状态与文件的跨文件原子性，也不代表真实 Provider 或人工验收。

## 评测历史损坏时保留原件

scoreboard 是权威历史：读取遇到损坏、格式错误或基准标识不一致时明确报错，不使用通用 JSON 自动恢复覆盖原件；主文件缺失但存在 .tmp 或 .bak 时也不会当作空历史。追加前发现未完成的 .tmp 会停止写入；创建基准前发现孤立历史或恢复文件会拒绝覆盖。列表读取采用同一规则，因此一个损坏的 scoreboard 可能暂时阻止基准列表，需先检查并恢复，不能把备份自动当成最新数据。定向测试覆盖原文件、备份和临时文件保留，以及正常评测回归；未实现自动恢复界面，也未解决跨进程读改写竞态或断电 fsync，旧记录不被回填。

## 自演化多次运行明细

自演化按 `runsPerCase` 多次评测并计算平均值；此前落盘仅保留首次会话，却把平均分写成单次运行分数。现将实际运行明细传给自演化记录，训练集和 held-out 的基线及接受候选均保留各次分数和会话 ID；测试以不同分数验证四类记录。历史记录不改写，也无法据此补回其丢失明细；测试采用替身评判，不代表真实 Provider、基准规则来源或业务验收。

## 每次评测的题目与评分规则摘要

新评测在读取每次案例题目文本和评分规则后计算 SHA-256，并随 baseline、自演化训练集及 held-out 各次运行保存；执行期间文件变更不会把本次已读取内容的摘要替换为新文件的摘要。历史记录不回填，摘要不保存规则正文。该摘要只覆盖读取时的题目与规则对象，不含案例素材、模型、评判者实现或后续进程内修改，也不证明执行完全受冻结输入约束；不能据此开放历史 scoreboard 可比门禁。自动化使用替身评判，真实 Provider 和人工验收尚未完成。
