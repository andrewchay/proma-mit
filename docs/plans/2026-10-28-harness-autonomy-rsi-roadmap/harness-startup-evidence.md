# Harness 调度开关启动接线

启动时读取本地 `harness-flags.json`，将 `toolScheduling` 应用于当前进程共享调度器。缺失文件沿用默认并行；显式关闭则串行运行并保留资源锁。

启动先切换到串行，再读取并应用配置。如果文件损坏，保留原文件并报告错误；即使启动错误处理打开降级窗口，调度仍为串行。随后修复配置并重启可恢复并行。仅影响本进程经共享调度器的调用，不代表跨进程或其他 Runtime 受相同调度。

测试使用临时目录与真实调度器，覆盖默认、关闭、恢复、损坏后串行；已通过主进程构建与类型检查。设置中的 Harness 策略面板显示启动时实际应用的调度状态，外部修改文件需重启，不提供热更新。尚未在打包 Electron 中验证启动错误提示或设置界面。
