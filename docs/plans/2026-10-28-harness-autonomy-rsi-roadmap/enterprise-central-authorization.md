# 企业集中授权模型（切片说明）

基线：`main` 08331f01（含 #79–#102）。本文件说明「集中授权」这一最大改造块的判定模型、
已落地部分与迁移顺序；成员登记、共享成果与审计的历史证据见
[enterprise-membership-evidence.md](enterprise-membership-evidence.md)。

## 现状与问题

- 工作区成员登记目前只影响「已发布成果」：所有者发布文件后，登记成员才能下载。
- 登记**不授予**工作区读写、会话或 Runtime 权限；接口固定返回 `sharedAccessEnabled: false`。
- 后果是权限判定散落在各入口：成员接口按 `scope.userId` 判断所有者，成果下载另有一套成员校验，
  工作区与 Runtime 完全没有成员概念。要开放共享工作区，必须先有唯一判定入口，
  否则每加一个入口就多一处可能写错的 if。

## 判定模型（已实现）

模块：`apps/server/src/workspace-access-policy.ts`，测试：`workspace-access-policy.test.ts`（10 例通过）。

`decideWorkspaceAccess(request)` 输入已认证身份、已读取的成员记录、目标动作与开关状态，输出
`{ allowed, reason, role }`。只做判定，不认证、不查库。

| 动作 | 所有者 | editor | viewer | 非成员 |
|---|---|---|---|---|
| `manage_members` | 允许 | 拒绝（role_insufficient） | 拒绝 | 拒绝（not_a_member） |
| `read_workspace` | 允许 | 开关开 → 允许 | 开关开 → 允许 | 拒绝 |
| `write_workspace` | 允许 | 开关开 → 允许 | 拒绝 | 拒绝 |
| `run_runtime` | 允许 | 开关开 → 允许 | 拒绝 | 拒绝 |
| `read_published_artifact` | 允许 | 允许（不看开关） | 允许（不看开关） | 拒绝 |

约束：

- **失败关闭**：未知动作、缺成员记录、成员记录 `userId` 与请求身份不一致、成员记录跨租户或跨工作区，
  一律拒绝并给出稳定原因码。
- **所有者只来自工作区记录**：`ownerUserId` 由工作区自身的 `user_id` 提供，不从成员表推导，
  成员表也没有 `owner` 角色，避免通过成员写入提权。
- **已发布成果不走工作区权限**：发布记录自带成员校验与版本核对，因此不受共享开关影响，
  与当前线上行为一致。
- **单一开关**：`isSharedWorkspaceAccessEnabled()` 只读环境变量 `GRAVITAS_SHARED_WORKSPACE_ACCESS === '1'`，
  默认关闭；成员接口响应中的 `sharedAccessEnabled` 改由它提供，不再硬编码。

## 迁移顺序（后续切片）

1. **读路径接线（行为不变）**：工作区读取入口改为调用判定函数，开关保持关闭；验收标准是现有
   所有者用例全部照旧、成员用例仍被拒且原因码可审计。
2. **成员接口自检**：成员登记/撤销在写入前用判定函数复核 `manage_members`，把「谁能管成员」
   从 `scope.userId === workspace.user_id` 收敛到同一处判定。
3. **Runtime 启动**：`run_runtime` 接进会话与执行器启动前置检查；同时决定 editor 能否创建会话、
   会话归属是否写入审计。
4. **写路径**：`write_workspace` 覆盖上传、发布、删除；发布记录需补「发布者角色」以便回溯。
5. **开开关**：仅在 1–4 全部完成并经过部署评审后设置 `GRAVITAS_SHARED_WORKSPACE_ACCESS=1`；
   开关打开前必须完成混合实例滚动部署检查。

## 未覆盖与风险

- 评估角色与现有 `operator`/`admin` 的关系：平台运维角色是否能越过工作区判定，需要单独定义，
  当前模型不含平台角色。
- 混合新旧实例滚动部署期间，旧实例不读取开关、也不做新判定，不能保证授权一致；需统一升级后验收。
- 真实身份提供方、邀请流程、生产对象存储（S3）、TLS 与外部审计投递仍未接入；本文与单元测试
  都不能替代客户环境验收。
- 成员记录撤销存在「判定通过后、请求执行中」的在途窗口；成果下载已有读取前后双检，
  工作区读写与 Runtime 尚未定义对应机制。

## 验收边界

- 已实现部分由单元测试覆盖判定表、失败关闭、跨租户/跨工作区不匹配与开关默认值。
- 未做端到端：没有入口调用该判定函数，因此本次不改变任何线上授权行为。
