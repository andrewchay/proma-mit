# Gravitas 产品定位简报

**核心受众与痛点**
面向 3–10 人的产品或研究团队。这类团队同时接多个模型供应商，在 Chat 与 Agent 两种形态间切换，上下文与配置容易散落（S1）；既需要隔离工作区，又要直接打开本地项目，数据不愿外流，偏好 JSON/JSONL 本地存储（S2）；协作中最怕技术评审通过被当成业务完成，目标、授权、评审、验收缺少分开的留痕（S3）。

**一句话定位**
Gravitas 是面向小型产品与研究团队的 Electron 桌面 AI Agent 工作台：多模型、可隔离、本地存储、过程可追溯。

**三个可追溯差异点**
1. 多供应商接入，Chat 与 Agent 双形态同台（S1）。
2. 工作区可隔离，也可直接打开本地项目，JSON/JSONL 本地存储优先（S2）。
3. 目标规划、执行授权、技术评审、业务验收分别记录，不把技术通过当业务完成（S3）。

**与通用聊天工具的取舍**
通用聊天工具开箱即用、零配置，适合一次性问答；代价是会话语境即全部上下文，缺少工作区隔离、本地结构化留存、审批与验收的分离记录。Gravitas 需先配置模型与工作区，并承担桌面端与本地文件的维护成本，换来隔离、可追溯和本地数据主权。取舍结论：轻量问答留在通用工具，需要多模型协作与可审计交付时用 Gravitas。

**未验证假设**
1. 3–10 人团队确实把本地存储与审计留痕列为选型关键。
2. 多供应商切换是高频真实痛点，而非偶发需求。
3. 四段分离记录不会被视为额外流程负担。
4. 团队愿意为上述能力接受 Electron 桌面端与初始配置成本。

以上假设均无用户访谈或竞品数据支撑，仅由 S1–S3 推导，需后续验证。
