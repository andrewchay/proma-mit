# AI Owner 目标驱动原型 v1

日期：2026-10-07 GMT+8。状态：可点击原型，待用户走查；不是 Electron 产品实现或安全门禁验收。

## 打开

用 Proma `BrowserPreviewOpen` 打开本目录 `index.html`，或在本地浏览器打开文件。没有外部资源、网络请求、模型调用、项目写入或持久化。刷新/重置会清空演示状态。

## 演示顺序

1. 默认选择非代码项目：提出目标及可选约束，Owner 提出步骤、推荐角色、成果与标准，不要求文件名/员工 ID。
2. 确认计划，查看独立执行边界；确认模拟边界后自动推进到成果，依赖无需逐项点开始。
3. 切换代码单任务，走相同目标流程；Review 提供示例变更，业务验收后仍需单独确认模拟应用。
4. “演示分支”可切换澄清、评审返工、超范围与异常；更换选项会重置当前演示。重置不是生产中的删除/撤权行为。
5. 可调整计划、暂停/恢复、给成果修改意见、拒绝范围建议、取消应用或关闭异常管理事项。

**固定示例限制：** 文本输入只用于展示/记录，不理解任意自然语言；修改意见不触发真实内容重写。角色、资料、费用、状态、验证和成果均标明模拟。草案默认资料只是示例，不声称已读取真实资料或继承有效配置。
