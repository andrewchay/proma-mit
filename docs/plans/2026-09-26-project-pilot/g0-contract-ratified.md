## 2. 契约条款（定案）

### C1 授权与命令账本
grant 版本化冻结（工作区/员工/渠道/模型/预算/次数/返工/有效期）；命令、预留、执行归属、排队状态同 SQLite 事务；幂等键同键同内容幂等、同键异内容拒绝；命令状态 `reserved → queued → running → settled/needs_reconcile`（含 released/cancelled）单向迁移留审计。**达成证据**：`project-pilot-budget-ledger.ts`、grant 发行/暂停事务（-38~-55）；G2 双 run 全程账实一致。

### C2 受控派发唯一入口
候选派发只经 `dispatchPilotIntent`：重读权威事实（任务/grant/策略/readiness/来源哈希），按任务负责人分角色（执行员工→executor、评审员工→reviewer，其余拒）；评审命令须存在已结算执行命令；`max_runs` 由账本强制；Pilot 模式禁用 Agent 子代理委派（fail-closed）。**达成证据**：`project-pilot-dispatch.ts`（-52/-58）；G2 第 1/2 run 真实派发。

### C3 证据与结算
逐请求：最终 HTTP body 派生请求身份（SHA-256 指纹）+ `include_usage` 强制 + 响应 tee；结算按证据价与同一套 ceil 算术，settled 释放差额；超预留/不可信转 needs_reconcile 保持占额；未知费用不当作零；结算幂等不改判；跨命令回执唯一约束防重放。**达成证据**：-55 系列 + `project-pilot-request-settlement.ts`；G2 11/11 请求逐笔 settled，bigmodel 账单核对完成（2026-09-29，用户确认）。

### C4 单请求费用边界（R1 裁定）
语义：**请求前证明最坏费用 ≤ 可用额度**。`calculatePilotRequestCeiling`：最坏费用 = ceil((输入上界 × 输入价 + 输出上界 × 输出价) / 1M) + 附加上界；输入上界由受控出口从最终 body 证明（非字符估算），输出上界 = max_tokens（含推理，Provider 服务端强制，G2 实测 thinking 计入且被封顶），价格来自版本库审核注册表（生产默认空 → fail-closed）。超可用额度 → 拒绝发送（HTTP 零字节）。**信任边界**：本地单机场景下受控出口所在主进程即信任边界；envelope 由出口拦截的最终 body 派生而非调用方自报；Provider 诚实回执的偏差由逐请求结算兜底（超占额 → needs_reconcile）。**达成范围**：ai-sdk runtime 已达成（-51/-52 + G2 实证）；任何 runtime 申请生产 readiness 必须实现等价的包络证明，Pi 线接线时按此验收。

### C5 人工验收闸门
AI 执行完成 → 任务「待人工验收」（交付快照冻结）→ 人工确认/应用后才 completed；技术评审通过 ≠ 业务验收；终态不冒充人工业务验收。**达成证据**：`writebackExecutionResult`、development-delivery/apply 流程；-60 审定确认。

### C6 停止与恢复闭环（R3 裁定）
暂停授权：同事务撤权 + 释放未排队预留 + 取消未启动 Pilot 队列；运行中逐项用户选择（完成本轮 / request_stop）；`request_stop` 持久记录（`pilot_stop_escalations`），**无进程终止证据时不宣称已终止**，转 needs_attention 人工对账——该保守分支即契约满足形态；绑定运行代际的终止证据增强列 P1。预算耗尽/授权过期立即阻止新派发。**达成证据**：`project-pilot-grant-pause.ts`、`project-pilot-stop-escalation.ts`；真实停止场景由 G1 故障矩阵补验。

### C7 双 Runtime 分线验收
proma 与 ai-sdk 长期并存，readiness/capability 按 runtime 逐项放行，禁止单条通过全局放开。ai-sdk：readiness 已放开（-56），生产费用链经 G2 验证。Pi：出口未接线、readiness 关闭，接线时按 C3/C4 同标准独立验收。**达成证据**：`project-pilot-readiness.ts`、AGENT_RUNTIME_CAPABILITIES。

### C8 needs_reconcile 释放（R2 裁定）
待对账占额在授权有效期内**永不自动释放**；仅两终态：① 人工确认结算（必须附 Provider 账单等外部证据，留审计）；② 授权过期随授权归档（审计留痕，额度不回流新授权）。旧项目（paused 授权 + $0.50 占额）即按本条处理的首个实例。
