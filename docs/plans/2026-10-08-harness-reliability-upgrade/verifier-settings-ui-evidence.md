> 2026-10-09 17:00 GMT+8。让受保护验证配置脱离“仅 API 可用”的状态。

## 实现

四层 IPC（shared 通道 → ipc.ts 处理器 → preload → 渲染页）：

- `VERIFIER_IPC_CHANNELS.LIST/SAVE`；渲染进程只能经此两通道读写，无文件直写能力。
- 主进程 `verifier-settings-service.ts`：list 返回摘要（修订、哈希、受保护路径、argv），损坏记录标记 `error` 不抛出；save 复用存储与模式校验（坏 id、空 argv、非法退出码、超时越界、最少测试数、非法路径全部拒绝）。
- 存储新增 `listIds()`。
- 设置页：设置 → 模型与智能体 → 「验证器」。列表 + 新建/编辑表单（argv 每行一个参数、退出码、超时、最少测试数、受保护路径每行一个模式）。编辑已有验证器需先点“确认修改”，并显示修订变化警告（保存后引用旧修订的 Goal 需重建）。
