## 费用与上限

- 上限：$0.6（按约 ¥5 保守折算；实际汇率未核验，若需精确人民币上限请告知）。
- 估算方法：请求级 `输入 token × 输入单价 + 输出 token × 输出单价`，单价取 Pi 目录的 DeepSeek 价（flash 0.3/1.2，v4-pro 1.32/3.96，单位 美元/百万 token），**忽略缓存折扣，偏保守**。这是本地估算，不是 DeepSeek 账单。
- 有效运行的估算合计：$0.1949；账本累计上限记录：$0.302（含第一轮统计修正前的估算，见下）。两者均低于 $0.6，未触发超额询问。

## 试点中发现并修复的问题

1. **Pi 的 deepseek provider 使用 Anthropic 兼容端点**（`https://api.deepseek.com/anthropic`）。用 OpenAI 根地址会 404。试点改用仓库默认地址。
2. **渠道模型注册时费用恒为 0**，导致 Pi 请求级费用闸门对所有带预算上限的 Pi 运行都失败关闭（“实际支出未知”）。修复：仅当渠道端点等于该 provider 官方默认地址且 Pi 目录收录该模型时使用目录价；第三方中转或未收录模型保持 0，仍失败关闭。新增 `pi-model-cost.test.ts` 三例。
3. 项目库需要 `initProjectDb()`，试点在临时配置目录内初始化，不触碰真实数据。
4. 证据统计把流式 partial 与最终消息相加，已改为只统计 final，答案取最后一条非空 assistant 文本。
