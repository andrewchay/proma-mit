## 可复现资料检查

```bash
python3 docs/ai-team/checks/validate.py docs/ai-team
```

只读取角色资料，不调用模型、不写应用配置。通过的是结构、完整性及静态边界，不是岗位能力或业务效果。

## 后续实例化门禁

只有用户选择 Runtime、启用渠道／模型及实际工作位置后，才可通过现有员工服务绑定真实实例。目录中的 roleSlug 不能代替 employeeId，也不应填假 channelId 绕过必填项。Shepherd 动态选择及执行须另接入权威身份、有效计划、授权和预算，不以创建目录或工作区视为执行许可。
