01

企业服务层 · 专业职能

财税、法务与经营分析，交给可配置的数字岗位

专业职能里最消耗人力的部分是重复的资料处理、规则核对与报表整理。 Gravitas 的做法是把这些工作定义成数字岗位：由 Agent 执行、由 Workflow 约束流程、由人负责关键判断。

平台机制已具备

典型场景

票据与台账处理

批量识别发票与单据，按规则核对归类，异常条目逐条外推确认后再进入后续流程，避免错账静默沉淀。

税务与合规核对

申报数据交叉比对、政策检索问答、风险点清单输出，每条结论附来源定位便于人工复核。

经营决策分析

从项目与业务数据生成周期报告、指标视图与偏差归因，把"数据在哪、谁负责、卡在哪一步"一次说清。

合同与法务支持

条款抽取、风险条款提示、标准模板比对与合同台账维护，把审阅前的准备工作自动化。

今天可用

  • 数字岗位执行框架：无人值守执行、任务级 Token 配额、需人工确认时外推到飞书 / 钉钉、执行全过程留痕。
  • 领域能力包机制：营销（26 个 Skills）与出海 sourcing 已按插件分发并跑通；财税、法务包可沿用同一套分发与权益门禁。
  • 外部系统连接：MCP 支持 OAuth 2.1 与客户端凭证、资源发现、凭据加密存储，可接入财务、ERP 与文档系统。
  • 经营治理指标：WIP、等待时长、30 天吞吐、平均周期、SLE 超时；项目级 AI 成本面板与 Token 统计。
  • 决策链与证据：DACI 拍板、结构化来源与校验值、决策版本替代关系、影响任务追踪。

规划中

  • 财税法专业能力包：票据结构化、申报核对规则库、政策检索与风险提示模板。
  • 经营决策分析增强：跨源数据接入与指标口径治理、归因与情景模拟、决策建议生成。
  • 外部证据自动对账与远端多人身份认证、职责强制分离。
02

运营效率层 · 智能调度

把「等人推进」变成「系统推进」

流程卡在谁那里、任务超时没人管、口头确认没有留痕，是运营效率最常见的损耗。 Gravitas 用工作流引擎与执行调度护栏接管这些环节，让人只出现在需要判断的节点上。

流程与调度底座已具备

典型场景

流程固化与自动流转

把反复要做的流程编成可视化执行链，按时间、事件或人工触发运行，节点失败自动重试或走错误分支。

任务派发与并发控制

任务分派到人或数字员工，同一项目内自动排队，避免并发冲突；需要判断时外推通知，不阻塞其他工作。

审批与例外升级

关键节点插入人工审批，驳回重走；超时与失败进入告警与升级链路，不再依赖人工盯守。

排班与产能调度（规划）

结合产能、技能与交期约束生成排程建议，并支持在约束变化时重排。

今天可用

  • Workflow 引擎：agent / tool / skill / transform / condition / approval 等节点可视化编排，支持手动、定时与事件触发，发布时可冻结节点能力白名单。
  • 执行调度护栏：同项目并发排队、心跳保活、乐观锁防冲突、僵尸任务诊断与恢复预案。
  • 服务端任务租约：跨 worker 租约与事件重放，实例故障不丢任务。
  • 成本与限速：租户 / 用户月度预算预检、单模型额度、固定窗口限速。
  • IM 联动：飞书 / 钉钉任务通知与状态双向同步，外部状态变化不打回本地进行中的工作。

规划中

  • 业务级排程引擎：产能、运力与技能约束下的优先级与 SLA 联合优化。
  • 实时事件接入（订单、MES、IoT）与在线重排、调度仿真与回放。
  • 移动端调度指令下发与现场确认回执。
流程闭环 触发→ 规则校验→ 派发执行→ 人工审批→ 复核验收→ 归档留痕
03

业务系统层 · CRM 与 ERP

不替换你现有系统，先把系统与 AI 连起来

企业很少愿意为了 AI 换掉 CRM / ERP。Gravitas 先做连接层：读授权数据、生成草稿、批量维护、 承接审批与验收；等场景稳定后，再把客户、订单、库存这类高频模块做成内建应用。

治理与连接底座已具备

典型场景

系统内嵌智能助手

在既有 CRM / ERP 工作流旁调用 Agent：查询授权数据、生成单据与跟进记录草稿、批量整理字段。

客户与商机跟进（规划）

客户 360 视图、商机漏斗、跟进 SOP 与销售助理，把散落在表格与聊天里的客户信息收拢。

审批与验收闭环

交付物版本化、验收标准逐项确认、交接双方确认，替代口头与聊天记录里的模糊承诺。

无接口老系统的受控操作

对没有开放接口的内部系统，用受管浏览器与桌面自动化执行受控操作，全程需要人工确认并留痕。

今天可用

  • 项目治理内核：任务表与自定义状态（按语义组归类、支持 WIP 上限）、看板拖拽一次落库、甘特图、依赖边与阻塞原因。
  • 责任与验收：负责人 / 验收人 / 接收人身份绑定，交付物版本化，验收标准冻结并逐项确认，交接需接收人确认。
  • 系统连接器：MCP（OAuth 2.1 与客户端凭证）、受管浏览器、桌面自动化，覆盖有接口与无接口两类系统。
  • 双向同步：飞书 / 钉钉字段与状态按语义组映射，外部轮询不覆盖本地进行中状态。
  • 垂直样例已验证：营销领域已实现达人库、分层与效果记录，同一机制可复用到客户与商机管理。

规划中

  • 通用 CRM 应用：客户 360、商机漏斗、跟进 SOP、AI 销售助理。
  • ERP 模块：采购、库存、订单、成本核算与财务凭证对接。
  • 标准化连接器：销售易、纷享销客、金蝶、用友、SAP 等主流 SaaS 的字段映射与同步配置台。
  • 主数据治理：字段映射配置、主数据校验与清洗。
04

生产现场层 · AI 视觉

识别结果直接进入流程，而不是停在报表里

视觉模型的价值不在单次识别，而在识别之后：谁来处理、多长时间内处理、有没有复核、结果有没有回写。 Gravitas 把视觉能力接在同一个工作流上，让「发现—工单—复核—处置」形成闭环。

底座已具备 · 工业视觉规划中

典型场景

质检判等（规划）

缺陷检测、尺寸测量与外观分级，超阈值自动生成工单并通知责任人，复核结论回写。

现场与设备巡检（规划）

巡检验收影像结构化归档，支持按对象、时间与事件回溯，异常片段自动定位。

图文与单据数字化

纸质单据、图纸、报表的批量识别与结构化，直接进入台账或业务系统字段。

内容与素材生产

分镜、图像生成与视频合成管线已在营销场景落地，可复用到产品与培训素材生产。

今天可用

  • 多模态与多模型路由：图片理解在内置 Chat / Agent 中可用；运行时可接入任意多模态模型，按能力与成本选择。
  • 批量处理能力：提供批量抽取、分类、打标签、OCR 与长文档处理的调用路径，含向量化能力。
  • 图像与视频创意管线：分镜 / 引擎 / 合成链路已在营销场景跑通。
  • 执行安全底座：服务端执行器只允许沙箱隔离执行，环境不具备隔离能力时直接拒绝执行；权限逐次确认并记录操作摘要。
  • 部署形态：本地优先客户端；私有化一键部署，含部署烟测与健康仪表盘。

规划中

  • 工业质检视觉：缺陷检测、尺寸测量、分级判等模型的接入与现场调优。
  • 视觉模型服务化：模型版本管理、效果对比与数据漂移监控。
  • 边缘部署与推理加速、产线设备（相机 / PLC）对接。
  • 质检结果闭环：异常 → 工单 → 复核 → 处置回写。

平台底座

为什么四层能力能落在同一个平台上

四层能力共享同一套运行时、编排、治理与安全机制。这意味着新增一层业务能力时， 不需要重新建设权限、审计、成本与运维体系。

落地路径

从一次可验证的场景开始，而不是一次性大改造

建议按三步推进：先连接、再固化、最后规模化。每一步都有可验收的产出，避免长期投入却看不到结果。

STEP 01

连接

接入你已有的系统与数据，先把只读查询和报表跑通，验证数据可达与权限边界。

  • 确认接入系统清单与账号权限
  • 连接 MCP / IM / 无接口系统的受控操作
  • 产出：一份用真实数据生成的报告
STEP 02

固化

挑一个高频、规则清楚的流程编成 Workflow，配上数字岗位与审批节点，稳定运行后再扩大范围。

  • 明确触发条件、审批点与失败处理
  • 设定成本配额与验收标准
  • 产出：可无人值守运行的流程
STEP 03

规模化

在验证有效后扩展到更多部门与业务系统，同时把权限、审计与运维对齐企业要求。

  • 私有化部署或服务端统一身份接入
  • 按部门划分工作区与权限范围
  • 产出：可复制到多部门的运行标准

安全与合规

企业级使用的前提是边界清楚

AI 进入业务流程后，真正决定能否长期使用的往往是权限、审计与数据边界这些细节。

分级权限与逐次确认

支持安全模式、询问模式与放行模式；改动文件、执行命令、联网与提交类操作按规则逐次确认，可对单个会话设置白名单，子任务不能自行批准高风险操作。

敏感步骤由人接管

密码、验证码、密钥、支付与最终提交等步骤进入专用接管状态，执行暂停直至人工完成，避免自动流程触碰不可逆动作。

操作可审计

关键操作记录摘要，可按来源、会话与操作类型筛选导出；服务端提供追加式审计与完整性校验，用于发现篡改。审计不记录页面正文、截图与敏感输入内容。

执行隔离

服务端代码执行只允许在沙箱隔离环境中进行；运行环境不具备隔离能力时直接拒绝执行，而不是降级放行。

数据边界与加密

本地优先存储，私有化部署时数据不出企业内网；密钥采用信封加密与轮换机制，渠道凭据加密保存。

成本护栏

支持租户、用户与单模型三级预算上限与调用限速，超出阈值前置拦截，避免用量意外。

关于专业结论与自动化边界： 财税、法务等专业场景中，AI 输出定位为辅助建议与初步材料，最终结论需由具备相应资质的人员复核确认； 涉及资金、申报、合同签署等不可逆动作，均需人工确认后执行。 此外，当前多人协作身份体系为本地单操作身份，远端多人身份认证与外部证据自动对账仍在建设中。
