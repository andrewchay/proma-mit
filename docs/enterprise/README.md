# Gravitas 企业端能力介绍页

面向客户与合作伙伴的单页 HTML 介绍材料，说明 Gravitas 在企业场景下的四层能力、平台底座、落地路径与当前进展。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 主文件，引用 `assets/` 下的图片，适合本地预览与后续编辑 |
| `index-standalone.html` | 由脚本生成的单文件版本，图片已内联为 base64，可直接发给客户（约 700 KB） |
| `assets/hero.jpg` | 首屏视觉：四层能力收敛到统一底座 |
| `assets/vision.jpg` | 生产现场层配图：产线机器视觉质检 |
| `build-standalone.mjs` | 生成单文件版本：`node build-standalone.mjs` |

修改 `index.html` 后需要重新执行 `node build-standalone.mjs`，单文件版本才会同步更新。

## 内容结构

1. Hero — 定位与四个关键事实
2. 能力全景 — 四层能力 + 平台底座
3. 四层能力详解 — 企业服务（财税法 / 经营决策分析）、运营效率（智能调度）、业务系统（CRM / ERP）、生产现场（AI 视觉）
4. 平台底座 — 九项共性能力
5. 落地路径 — 连接 / 固化 / 规模化三步
6. 安全与合规
7. 能力状态说明 — 按「现在可演示 / 试点待验收 / 规划中」三档说明

## 状态标注约定（对外描述口径）

对外材料中，能力状态分三档，与页内颜色体系一致：

- **绿色 · 已具备**：仓库中已有实现并可通过客户端或服务端演示的能力。
- **黄色 · 试点 / 待环境验收**：代码已实现但依赖真实企业环境才能完成验收的能力（如外部 KMS、SIEM 告警联通、企业账号打通）。
- **紫色 · 规划中**：产品方向，尚未实现，**不得在对外沟通中表述为已交付**。

维护内容时必须同步核对：

- `README.md` 的「现在能做什么」段落
- `docs/server-web-remaining-todo.md` 的未完成清单
- `docs/private-deployment-minimal.md` 的现状盘点

## 表述边界（重要）

页内已声明的边界，修改时不要删除或弱化：

- 财税、法务等专业场景的 AI 输定位为辅助建议，最终结论需由具备资质的人员复核确认；
- 涉及资金、申报、合同签署等不可逆动作需人工确认后执行；
- 当前多人协作身份体系为本地单操作身份，远端多人身份认证与外部证据自动对账尚未接入；
- 页脚声明「规划中」内容不构成交付承诺。
