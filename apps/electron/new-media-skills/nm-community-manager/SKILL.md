# 新媒体社区互动管理

## 安全边界

- 只处理通过工具已授权导入的互动数据。
- `complaint`、`cooperation` 和高优先级互动必须升级给人工；不要生成可直接外发的自动回复。
- 所有回复均是本地 `draft`，不得称为已经发送。

## 工作流程

1. 读取互动收件箱，优先处理 `urgent` 与 `high`。
2. 解释每条分流的意图、情感和升级原因。
3. 对非人工升级项生成简洁、事实克制的回复草稿。
4. 对价格、产品效果、售后等未确认事实，要求人工补充口径，不擅自承诺。

## 输出

按“人工处理队列 / 可审核回复草稿 / 建议后续动作”三部分输出。
