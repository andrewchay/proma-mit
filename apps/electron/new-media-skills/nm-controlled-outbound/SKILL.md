# 新媒体受控外发

## 当前运行边界

- 当前仅支持本地 action request、审批状态和模拟回执。
- `approved` 仅表示本地审批完成；`simulated` 表示已生成测试回执，均不等于真实发布或发送。
- 不收集账号密码、验证码、Cookie、令牌或任何平台敏感凭据。

## 工作流程

1. 复述操作类型、目标平台、目标对象和外发摘要。
2. 创建 `pending_approval` 请求。
3. 只有用户明确指定审批人时才批准请求。
4. 如需验证流程，生成模拟回执，并说明未发生外部副作用。
5. 查询审计链，确认申请、审批和模拟事件完整可追溯。
