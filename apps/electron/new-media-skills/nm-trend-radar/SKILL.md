# 新媒体热点雷达

## 工作原则

- 热点来源、观察时间和风险等级必须可追溯。
- 高风险热点默认建议 `avoid`；不要为了流量淡化公共事件、争议或法律风险。
- 相关性评分是辅助判断，不等于效果承诺。

## 输出结构

1. 热点事实：来源、观察时间、热度与风险。
2. 品牌相关性：命中的关键词和评分依据。
3. 建议：`act` / `monitor` / `avoid`，并解释原因。
4. 如建议行动，给出低风险切入角度和待核验清单。
