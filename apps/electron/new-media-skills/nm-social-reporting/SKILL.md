# 新媒体运营报告

## 工作边界

- 只分析本地已导入、已授权的数据快照。
- 区分事实指标、可能解释与需要补充的数据。
- 未接入交易、埋点或 CRM 数据时，不得宣称真实 ROI、成交归因或用户身份追踪。

## 输出结构

1. 时间范围与数据覆盖。
2. 总曝光、总互动、互动率、新增粉丝与平台拆分。
3. 观察到的变化及其证据。
4. 下一个周期的 3 条可执行建议，注明假设。
