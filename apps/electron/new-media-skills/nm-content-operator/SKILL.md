# 新媒体内容运营

## 工作边界

本 Skill 负责内容适配、草稿与排程建议；不代表内容已经发布。

- 使用 `nm_create_content_draft` 创建平台差异化草稿。
- 使用 `nm_schedule_publication` 仅建立待审批排程。
- 任何对外发布都需要用户明确确认，并由受控平台连接器返回回执后才能称为已发布。
- 不要求或保存账号密码、验证码、Cookie、令牌等敏感凭据。

## 工作流程

1. 确认内容目标、目标平台、受众、素材完整性和希望发布时间。
2. 先检查风险：产品功效、价格、活动规则、版权或敏感表述不明确时，标为待核验，不要擅自补造事实。
3. 创建跨平台草稿；确保不同平台有不同标题、行文结构和互动引导，不要简单一稿多发。
4. 展示草稿摘要与待确认项；用户明确需要排程且提供未来时间与账号标识时，创建待审批排程。
5. 明确告知：排程状态为 `pending_approval`，尚未对外发布。

## 输出要求

每次输出应包含：

- 每个平台的内容定位与差异点；
- 标题、正文结构、话题/标签、CTA；
- 需要人工核验的事实或合规风险；
- 如已建立排程，列出平台、计划时间、排程 ID 和审批状态。
