# 跨平台内容日历规划

## 这个 Skill 做什么

基于创意概念和策略方向，生成系统性的跨平台内容日历：
- **月度/季度主题规划**：每月核心主题和热点借势
- **周度拆解**：每周重点和各平台的具体内容安排
- **内容配比**：品牌向/产品向/互动向/热点向的比例建议
- **发布节奏**：各平台的发布频率和最佳时间

## 何时使用

**合适的场景：**
- 社媒运营的月度/季度规划
- Campaign 执行的具体排期
- 多平台内容统筹和分发策略
- 热点日历与品牌内容的结合规划
- 新账号启动前的内容储备规划

**不合适的场景：**
- 单次内容创作（不需要日历级别规划）
- 实时热点追蹭（日历规划至少提前2周）
- 没有明确创意概念或策略方向时

## 工作流

### Step 1 · 需求确认

确认以下信息：
| 信息项 | 说明 |
|--------|------|
| 时间范围 | 月度 or 季度 |
| 创意概念 | Big Idea 或核心传播主题 |
| 目标平台 | 运营的平台列表 |
| 内容支柱 | 已确定的内容支柱 |
| 预算级别 | 影响内容配比（原创 vs UGC） |
| 关键节点 | 品牌节点、行业节点、社会热点 |

### Step 2 · 日历生成

生成包含热点、周度拆解、内容配比和里程碑的完整日历。

### Step 3 · 可执行性检查

检查日历的可执行性：
- 内容产出量是否在团队产能范围内
- 热点内容是否提前至少2周规划
- 各平台内容是否有差异化，避免一稿多发

## 规则

1. **每个平台的内容角度必须不同**，避免全平台发同样内容（如一稿多发）
2. **content_type** 分为：品牌向、产品向、互动向、热点向
3. **热点内容必须提前2周规划**，不能临时凑，标注明确的准备周期
4. **cta 要具体**，不是"欢迎互动""喜欢就点赞"这类空话，要具体到动作
5. 如果预算极低，增加 **ugc_interaction** 占比，减少原创比例
6. 发布频率要符合平台特性和团队产能，不要盲目追求高频
7. 月度主题要与创意概念保持连贯，每月推进一个子主题
