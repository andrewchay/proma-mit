# 市场分析

## 这个 Skill 做什么

基于目标品类与行业背景，系统化分析并输出市场输入，覆盖三大板块：

- **市场规模**（market size）：大盘数据、品类增速、渗透率、市场容量、细分赛道占比
- **品类趋势**（category trends）：当前所处周期（上升/平稳/衰退）、用户偏好变化、平台趋势、技术/政策驱动
- **品类痛点**（pain points）：用户未被满足的需求、行业普遍问题、空白切入点、机会点评估

## 何时使用

**合适的场景：**
- 品牌定位前的市场机会判断
- 新品上市前的品类容量评估
- 营销 campaign 前的趋势切入选择
- 竞品分析 / 用户分析之前的基础层输入

**不合适的场景：**
- 已有完整市场研究报告、无需重新分析
- 纯落地执行（货架、投放排期），不涉及市场判断

## 工作流

### Step 1 · 收集品类与背景

| 信息项 | 说明 |
|--------|------|
| 目标品类 | 所属行业与细分赛道 |
| 投放区域 | 国内 / 海外，影响参考数据口径 |
| 客单价带 | 产品价格区间，辅助市场规模判断 |
| 已有资料 | 是否已提供报告、数据、竞品清单 |

若信息不足，标注「待补充」并降低 confidence_score，不硬编造数据。

### Step 2 · 市场分析

按下方输出格式构建三大板块，**必须在正文中明示**：
- 以「**市场规模**」为板块标题，正文包含不少于 100 字的市场规模 / 大盘 / 增速 / 渗透率 / 市场容量分析
- 以「**品类趋势**」为板块标题，正文包含不少于 100 字的品类趋势 / 周期 / 偏好变化 / 趋势机会分析
- 以「**品类痛点**」为板块标题，正文包含不少于 100 字的痛点 / 未被满足需求 / 空白切入点分析

### Step 3 · 数据来源标注

每条关键数据标明来源或口径（如艾瑞咨询、增长黑盒、品类报告、公开财报、推算口径），无法核实的标记为「推算 / 待核实」。

## 输出格式

工作流 / 生成到 `market-analysis/` 目录的上下文中，**必须将分析保存为 `market-analysis/market-analysis.md`**（Markdown），结构如下：

```markdown
# {品类} 市场分析

## 市场规模
（至少 100 字：大盘规模、增速、渗透率、容量、细分占比）

## 品类趋势
（至少 100 字：所处周期、用户偏好变化、平台/技术/政策驱动、趋势机会）

## 品类痛点
（至少 100 字：未被满足的需求、行业普遍问题、空白切入点）

## 数据来源
- 来源/口径 1
- 来源/口径 2（无法核实的标注"推算/待核实"）
```

**正文必须原样保留「市场规模」「品类趋势」「品类痛点」三个小标题**，并在每个板块内自然使用对应关键词（如规模、大盘、增速、渗透率、市场容量；趋势、周期、偏好变化、趋势机会；痛点、需求、未被满足、空白、机会点），确保机器人校验可识别。

## 规则

1. **三大板块标题必须字字精确**：「市场规模」「品类趋势」「品类痛点」，不要改成近义词（如"大盘情况""用户需求"）。
2. 每个板块不少于 100 字，全篇建议 400 字以上，避免空泛套话。
3. 数据优先给区间与量级，标注来源与口径；不确定的明确写「推算 / 待核实」，不编造精确到离谱的假数据。
4. 面向落地：最终给出 1-2 个可切入的趋势机会点与空白。
5. confidence_score 诚实评估（0-100），信息不足时降低并标注缺失项。
