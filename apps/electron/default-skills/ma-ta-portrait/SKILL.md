# 目标受众（TA）画像构建

## 这个 Skill 做什么

基于品牌信息和行业背景，构建完整的 TA 画像，并提炼可用于传播的消费者洞察：
- **核心 TA**：人口统计、心理特征、消费行为、痛点与欲望
- **潜质 TA**：与核心 TA 的差异和激活策略
- **社交语言**：TA 的真实用语和表达习惯
- **Persona 原话**：模拟 TA 的口吻和情绪
- **消费者洞察（Consumer Insight）**：带张力的人性真相，区分 Observation 与 Insight
- **传播切入点（Entry Point）**：基于洞察的传播角度

## 何时使用

**合适的场景：**
- 品牌定位前的受众洞察
- 内容策略制定时的受众校准
- KOL 筛选标准的建立
- 创意概念验证时的受众匹配
- 新市场/新品类拓展时的受众探索

**不合适的场景：**
- 已有详细用户研究报告时
- 纯执行层面的单次内容创作
- B2B 企业的决策链分析（需要不同的分析框架）

## 工作流

### Step 1 · 信息收集

收集以下信息：
| 信息项 | 说明 |
|--------|------|
| 品牌/产品 | 核心功能和卖点 |
| 行业背景 | 品类特征和消费习惯 |
| 现有客群 | 已知的用户特征（如有） |
| 价格带 | 影响目标人群的收入层级 |
| 投放区域 | 国内/海外，影响文化背景 |

### Step 2 · 画像构建

基于信息构建核心 TA 和潜质 TA 的完整画像。

### Step 3 · 验证

通过 persona_quotes 验证画像是否真实可信。

### 工作流落盘规范（写到 user-analysis/ 目录）

1. `ta-portrait.md` — 目标受众画像，必须包含并明示小标题与措辞：
   - `## 人口统计`：年龄 / 性别 / 收入 / 城市 / 地域 / 学历 / 职业
   - `## 兴趣偏好`：兴趣 / 偏好 / 爱好 / 生活方式 / 消费观
   - `## 痛点需求`：痛点 / 需求 / 场景 / 问题 / 欲望 / 动机（含购买的 battle 与 barrier）
2. `search-habits.md` — 搜索习惯：
   - `## 搜索平台`：小红书 / 抖音 / 百度 / 知乎 等
   - `## 搜索场景`：种草前 / 决策中 / 使用后
   - `## 搜索关键词`：核心词 / 长尾词 / 竞品词列表
3. `consumer-insight.md` — 消费者洞察与传播切入点：
   - `## 消费者洞察`：Observation（现象）与 Insight（动机/冲突），带人性张力
   - `## 传播切入点`：entry point，创意团队可直接发想的传播角度

三份文件合计不少于 300 字；每份小标题必须字字精确（如「兴趣偏好」「搜索习惯」「消费者洞察」「传播切入点」），并在正文自然使用关键词（兴趣、偏好、搜索、关键词、洞察、insight、切入点），确保机器人校验可识别。

在**非工作流**的普通对话中：仍按下方 JSON 输出。

## 规则

1. **pain_points 和 desires 要形成张力**，如"想要专业表现，也在意风格表达""追求效率，但不愿牺牲品质"
2. **social_terms 要用 TA 的真实语言**，不是品牌语言，如"绝了""狠狠爱住"而非"卓越品质"
3. **persona_quotes 要像真实用户说的话**，带情绪和细节，避免"这个产品很好用"这类平淡表达
4. **potential_ta** 必须有明确的 **gap_from_core** 和 **activation_strategy**
5. 如果是海外投放，增加文化背景和当地社交平台习惯
6. consumption_behavior 要具体到平台和行为，如"小红书搜索→收藏→比价→下单"
7. **insight 必须带张力**：不是"消费者喜欢美的"这类常识，要体现人性冲突，如"想要专业表现，也在意风格表达"
8. **observation 是现象，insight 是动机**： observation 描述"看到什么"，insight 解释"为什么这样"
9. **entry_point 必须可传播**：是创意团队能直接发想内容的入口
10. confidence_score 诚实评估，信息不足时降低分数并标注缺失项
