# 品牌 DNA 提取

## 这个 Skill 做什么

基于提供的品牌资料，系统性地提取品牌 DNA，包括：
- **品牌传承**（heritage）：历史根源和文化传承
- **核心价值**（core_values）：消费者能直接感知的产品/功能价值
- **附加价值**（added_values）：情感、文化、生活方式层面的价值
- **品牌人格**（personality_traits）：3-5个具体的形容词描述
- **产品定位**（product_positioning）：品类利益点、差异化、证据点

## 何时使用

**合适的场景：**
- 品牌策略制定或品牌焕新项目
- 新产品上市前的品牌诊断
- 品牌与竞品差异化梳理
- 品牌内容创作前的调性校准
- 品牌联名或跨界合作前的匹配评估

**不合适的场景：**
- 已有明确品牌手册且无需更新的日常执行
- 纯战术层面的单次内容创作（不需要深度品牌分析）

## 工作流

### Step 1 · 资料收集

向用户收集以下信息（如果缺失则标注为「待补充」）：
| 信息项 | 说明 |
|--------|------|
| 品牌历史 | 创立背景、发展历程、里程碑事件 |
| 产品/服务 | 核心产品线、功能卖点、价格带 |
| 目标人群 | 现有客群画像、理想客群 |
| 品牌愿景 | 品牌使命、长期目标 |
| 视觉资产 | Logo、包装、视觉风格描述 |
| 现有传播 | 过往 campaign、slogan、核心文案 |
| 竞品对标 | 直接竞品和 aspiration 品牌 |

### Step 2 · DNA 提取

基于收集的资料，按照下方输出格式进行系统分析。

> **工作流/生成到 `brand-dna/` 目录的上下文中，必须将分析落盘为 Markdown 文件保存到 `brand-dna/` 目录**（建议命名 `brand-dna.md` / `brand-diagnosis.md` / `differentiation.md`）。
> 落盘正文必须明示并用精确措辞：
> - `## 产品/服务`：正文含「产品」「服务」「功能」「卖点」「价格」「价格带」「产品线」等词，描述核心产品线、功能卖点、价格带。
> - `## 产品现状`：正文含「产品力」「供应链」「价格带」「SKU」「产品诊断」等词，给出产品力与供应链现状诊断。
> 其余板块（品牌历史、品牌阶段、核心问题、核心目标、差异化优势）亦保持小标题精确。全篇合计不少于 300 字。

### Step 3 · 验证与校准

向用户确认提取结果是否准确，特别是：
- heritage 是否挖掘到足够深的文化根源
- personality_traits 是否是团队公认的品牌人格
- differentiator 是否真正区别于竞品

## 输出格式

必须以 JSON 格式返回：

```json
{
  "status": "complete | partial | insufficient",
  "missing_fields": ["缺失字段名"],
  "brand_dna": {
    "heritage": "品牌传承与历史根源",
    "core_values": ["有形价值1", "有形价值2"],
    "added_values": ["附加价值1", "附加价值2"],
    "personality_traits": ["人格形容词1", "人格形容词2", "人格形容词3"],
    "tone_of_voice": "品牌语气的一句话描述"
  },
  "product_positioning": {
    "category_benefit": "品类级利益点",
    "differentiator": "与竞品最核心的差异",
    "proof_points": ["证据点1", "证据点2"]
  },
  "confidence_score": 85
}
```

## 规则

1. **heritage** 要挖掘品牌的历史根源和文化传承，不只是成立时间
2. **core_values** 是消费者能直接感知的产品/功能价值，不是企业价值观
3. **added_values** 是情感、文化、生活方式层面的价值，要具体到场景
4. **personality_traits** 用3-5个形容词，避免空泛（如"优秀的""专业的"），要有画面感
5. **tone_of_voice** 要具体到语言风格，如"像一个懂行但不炫耀的朋友"
6. 如果资料不足，**status** 标记为 `partial` 并列出 **missing_fields**
7. **confidence_score** 基于信息充分程度打分（0-100），诚实评估
