# 竞品社媒诊断分析

## 这个 Skill 做什么

基于提供的竞品信息，进行系统性的社媒账号诊断和竞争情报分析：
- **竞品洞察**：识别每个竞品的优势、内容模式和内容缺口
- **市场机会**：发现可切入的机会点，评估难度和预期影响
- **差异化建议**：给出可执行的品牌差异化方向

## 何时使用

**合适的场景：**
- 品牌定位前的竞品格局扫描
- 社媒策略制定时的对标分析
- 寻找差异化内容突破口
- 新品牌入市前的竞争环境评估
- 季度/年度策略复盘时的竞品追踪

**不合适的场景：**
- 没有竞品信息或无法获取竞品数据时（输出质量会大幅降低）
- 纯创意执行阶段（不需要竞争分析）

## 工作流

### Step 1 · 竞品信息收集

收集以下信息（允许基于公开信息推断，但需标注）：
| 信息项 | 说明 |
|--------|------|
| 竞品名称 | 直接竞品和间接竞品 |
| 竞品平台 | 主要运营的社媒平台 |
| 内容样本 | 近期帖子、campaign、互动数据 |
| 用户反馈 | 评论区、用户评价的倾向 |
| 品牌定位 | 竞品的定位主张和核心卖点 |

### Step 2 · 社媒诊断

对每个竞品进行社媒账号诊断，识别内容模式和缺口。

### Step 3 · 机会与差异化

基于诊断结果，提出市场机会点和差异化建议。

## 输出格式

必须以 JSON 格式返回：

```json
{
  "status": "complete | partial | insufficient",
  "competitor_insights": [
    {
      "competitor_name": "竞品名",
      "platform": "平台名",
      "strengths": ["优势1", "优势2"],
      "content_patterns": ["高频内容形式1", "高频内容形式2"],
      "gaps": ["缺失板块1", "缺失板块2"],
      "audience_sentiment": "用户对竞品的情感倾向描述"
    }
  ],
  "market_opportunities": [
    {
      "opportunity": "可切入的机会点",
      "rationale": "为什么这是机会",
      "difficulty": "low | medium | high",
      "expected_impact": "low | medium | high"
    }
  ],
  "differentiation_recommendations": ["差异化建议1", "差异化建议2"],
  "confidence_score": 80
}
```

## 规则

1. **strengths** 必须具体，避免"内容很好""粉丝很多"这类模糊描述，要具体到策略层面
2. **gaps** 要基于内容板块的缺失，不只是"做得不够好"，而是"完全没有覆盖"
3. **market_opportunities** 必须说明 **difficulty** 和 **expected_impact**，帮助用户优先级排序
4. **differentiation_recommendations** 要可执行，不只是方向性描述，要具体到行动
5. 如果没有提供竞品内容样本，基于公开信息推断并明确标注 "基于公开信息推断"
6. 差异化建议要避开"模仿竞品但做得更好"的思路，寻找真正的差异化空间
