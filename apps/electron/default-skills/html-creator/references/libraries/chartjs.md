# Chart.js 最小用法

何时使用：仅新建页面或本次需求要新增趋势、比较、构成、分布或多期等量化关系图表时加载 Chart.js；仅展示 KPI、数据表、文字结论或无数值的定性流程/架构图时不加载，编辑存量页面但不新增图表时不补引。

新建量化关系图表时，先放带唯一 id 的 `canvas`，再在页面尾部创建图表。共享 `responsive: true`、`maintainAspectRatio: false`、简洁 tooltip、隐藏无用网格线，限制 canvas 高度；标签采用页面字体。折线使用少量点和适度 `tension`，柱状图让分组、单位和颜色直接可读，环图类别尽量不超过四个。禁止以 CSS/div 或手写 SVG 代替；不要把默认 Chart.js 配色、图例和边框原样留给用户。编辑没有 Chart.js 的存量页面而未新增图表时，不要补引该库。
