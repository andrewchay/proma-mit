# 分屏滚动产品叙事 Split-Screen Product Narrative（固定证据台+章节式讲解）
> 用户展示名：浅色 · 蓝色点缀的左右分屏产品页
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原90%`

- 参考:Apple Vision Pro 产品页 / Stripe 产品叙事页 / Nothing 产品说明；杂志跨页版式与产品演示的混合
- 适配:复杂 SaaS、开发者工具、硬件功能介绍、功能较多但需要逐段解释的转化页；适合“一个核心价值＋4–6 个证据”的内容，而非信息总览。
- 视觉DNA:配色暖白#F7F5F0+墨黑#161616+信号蓝#2457F5+雾灰#D9D6CF，章节只用一处高饱和强调。字体紧凑无衬线结论标题×等宽数字/参数。布局桌面左侧 42% 固定为产品证据台，右侧为长滚动章节；每章切换一张简化 UI、图表或结构图。标志元素：固定的“证据舞台”、滚动驱动的章节编号与状态条。
- HTML实现:Tailwind Grid + `sticky top-0 min-h-screen` 构建左右两栏，右侧使用语义 section 与 `scroll-snap` 可选增强；证据台内用 CSS/SVG/已获授权的真实图片素材替换内容，不伪造产品截图。小屏取消 sticky，改为每段“结论→证据”顺序堆叠；无滚动动画也保留章节状态与强对位，主体可达90%。
- 字体映射：默认使用系统字体栈实现。参考气质：Inter / SF Pro（紧凑无衬线）+ Geist Mono（参数），映射为 system-ui + ui-monospace。
