# 镜像业务对照 Mirror Change Axis (前后状态×变化轴)
> 用户展示名：浅色 · 钴蓝主线的项目复盘
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原94%`

- 参考:转型项目复盘、产品迁移说明、现代信息设计中的对照版式；保留“变化前后在同一坐标中被阅读”的机制，不复刻任何咨询模板。
- 适配:流程升级、系统替换、项目复盘、客户案例、运营转型与产品改版说明；适合有清晰旧状态、新状态、采用过程和结果口径的内容。选择它而非 Decision Spread Proposal，当页面主任务是解释“从哪里改变到哪里”，而非为一项决策逐条陈述提案与责任。
- 视觉DNA:配色=近白#FFFEFA、墨黑#171716、钴蓝#2358D8、规则灰#D1D0C9；字体=全程中文无衬线，判断句 650 字重、正文 1.8 行高、数字与周次等宽；布局=首屏定义旧/新状态，中段用贯穿的蓝色变化轴承接采用轨迹与关键数据，末段把结果回扣到最初判断；标志元素：镜像对照框、中央变化箭头、沿轴增长的单结论图。
- HTML实现:使用 CSS Grid 实现左右状态与中心轴，量化采用轨迹必须由 Chart.js canvas 表达并写清时间口径；简单前后比较可用语义化 HTML，禁止用渐变、玻璃卡和伪装数据的 CSS 柱图。移动端顺序固定为旧状态→变化动作→新状态→采用证据→结论，中央轴退为纵向步骤线；无可信数据时只呈现已验证改变和待验证假设。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，数字/阶段使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Inter / Helvetica Neue；以系统无衬线实现。
