# 提案决策地图 Proposal Decision Map（问题—选项—取舍—推荐）
> 用户展示名：浅色 · 决策蓝点缀的方案取舍图
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 演示 deck · 中性派 `中性·还原96%`

- 参考:Service Design Blueprint / GOV.UK service maps / 战略咨询决策页；把讨论收敛为可选择的路径
- 适配:项目提案、方案说明、客户决策会、战略共创；适合有多种方案、约束与明确推荐的内容。
- 视觉DNA:配色暖灰#E8E3D7+墨黑#181817+决策蓝#2457F5+风险橙#F05A28，蓝专属推荐路径。字体理性无衬线×等宽假设标签。母版=①问题框定②选项比较③取舍地图④推荐路径与下一步。标志元素：路径箭头、选择条件、把“不做什么”显性化。
- HTML实现:Reveal + Mermaid 表达分支/依赖，2–4 个简单选项可用原生 HTML；一页只呈现一个决策层，表格不超过5列。所有 section 使用 `.slide-content`，手机预览不以缩小文字塞入；无图片也能以路径图和真实约束完成。
- 字体映射：默认使用系统字体栈实现。参考气质：IBM Plex Sans + IBM Plex Mono，映射为 system-ui + ui-monospace。
