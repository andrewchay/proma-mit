# 浅底暗面叙事 Light-Dark Narrative (阅读面×结论暗场)
> 用户展示名：浅色 · 黑白黄年度故事页
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原94%`

- 参考:高端咨询发布页的章节切幕 / 现代企业年报的深浅节奏 / Apple 叙事型产品页的结论停顿；继承的是阅读节奏，不复制品牌素材。
- 适配:公司介绍、品牌叙事、年度回顾、业务线发布与 narrative landing page；适合已有明确判断、少量可信数据和 1—3 个案例，但没有摄影素材也必须成立的内容。选择它而非 Narrative Brand Atlas，当重点是用明暗章节组织记忆点，而不是使用连续坐标轴讲故事。
- 视觉DNA:配色=近白#FFFEFA、深墨#1A1B1A、规则灰#D3D2CB、信号黄#EED82B（黄只标记结果或行动，面积≤5%）；字体=全程中文无衬线，标题 650—700 字重、正文 400—500、数字等宽；布局=连续白底阅读面承载解释与证据，深墨整带只承载一句结论、大数字或转场，避免把每个段落封进卡片；标志元素：反差章节幕、暗场左侧结果线。
- HTML实现:用语义 section 和内层容器分开背景舞台与内容对齐，深色段直接用 CSS 色块而非渐变；证据用真实数字、Chart.js 单图或简洁 HTML 对照，禁止虚构摄影。桌面端白段保持 30—50 汉字行宽，手机端顺序固定为标题→摘要→结论暗场→证据→行动，深色整带改为自然高度且不使用绝对定位。无可靠量化数据时，暗场退化为可核验的项目判断或引语。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，数字/章节号使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Helvetica Now / Inter；以系统无衬线和字重层级实现。
