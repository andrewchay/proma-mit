# 角色色叙事 Role-Color Narrative (角色语义×协同行动)
> 用户展示名：浅色 · 蓝红绿黄分区服务介绍
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 大胆派 `大胆·还原92%`

- 参考:服务蓝图、协同产品介绍、现代信息设计的语义色编码；只继承“颜色让角色与责任更易读”的机制，不复制组织图或人物插画。
- 适配:公司能力、平台服务、多角色协同、业务线介绍与复杂产品落地页；适合调度、现场、客户、伙伴等角色都需要看懂自己下一步的内容。选择它而非 Capability Proof Grid，当核心问题是让不同读者迅速知道“这条信息与谁有关”，而不是浏览能力模块。
- 视觉DNA:配色=暖白#FAF8F2为首屏与大部分阅读基底+钴蓝#3159E8（调度/判断）、珊瑚#EF5B3E（现场/行动）、青绿#16845B（客户/复核）、荧黄#CCE83F（共同焦点），四色仅在相应角色与章节中使用；字体=中文无衬线标题与正文、等宽角色标签；布局=首屏建立共同事件与四色角色区域，后续以角色带、事件链和对应结果展开，不把内容塞进均等卡片；标志元素：角色色轨、同一事件的三段责任带。
- HTML实现:CSS Grid 构建角色带和事件流，复杂角色关系才使用 Mermaid；真实产品截图可在事件视图位置替换，无图时用状态、责任与结果的结构化文本。手机端按共同事件→调度→现场→客户→结果堆叠，角色色同时配合文字标签，不能只靠颜色传达身份；禁止渐变、卡通人物、彩虹色和背景装饰泛滥。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，角色/状态/时间使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Inter / IBM Plex Sans；以系统无衬线实现。
