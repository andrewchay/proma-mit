# 能力证据网格 Capability Proof Grid（方法模块+量化证明+接口关系）
> 用户展示名：浅色 · 深蓝点缀的网格团队介绍页
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原95%`

- 参考:IDEO 能力页 / Pentagram casework / BCG X；专业服务的“证据优先”版面
- 适配:团队介绍、服务能力、咨询方案、业务线介绍；适合把抽象能力转化为方法、案例和结果的页面。
- 视觉DNA:配色近白#F8F7F3+炭黑#181817+规则灰#D9D6CF+深蓝#173EA5，蓝仅标记已验证证据。字体理性无衬线×等宽标签。布局 12 列基线网格，能力域作为大模块，方法/成果/客户场景作为不同尺度的证明单元。标志元素：编号能力链、证据标签、跨模块接口线。
- HTML实现:Tailwind Grid 做不等跨度模块，重复的证据块收敛为语义类；可用 Mermaid 表达复杂能力关系，简单关系以 HTML 连线呈现。手机端按“能力→方法→成果”重排，不保留难读横向大网格；无需照片，图表与真实案例数据即可成立。
- 字体映射：默认使用系统字体栈实现。参考气质：IBM Plex Sans + IBM Plex Mono，映射为 system-ui + ui-monospace。
