# 服务路线长卷 Service Route Scroll (区域节点×交付路线)
> 用户展示名：浅色 · 深绿主线的服务路线长页
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原92%`

- 参考:服务网络说明、基础设施项目路线图、跨区域交付报告；继承路线和节点的叙事结构，不做后台地图、控制台或地理信息大屏。
- 适配:业务线介绍、多城市服务、行业解决方案、伙伴网络、交付体系与区域复制计划；适合需要同时交代“服务如何抵达现场、每个节点做什么、覆盖后是否稳定采用”的企业内容。选择它而非 Milestone Signal Timeline，当路线的主体是服务/区域/场景，而不是单一项目的时间进度。
- 视觉DNA:配色=雾白#F7F7F3、深绿#1D5543、炭黑#171716、规则灰#D1D0C9；字体=中文无衬线主标题×等宽城市和节点字段；布局=总覆盖数字开场，连续路线将接口准备、班组试点、客户验收等服务节点串联，每个区域以小体量事实块落地，最后收束到站点、续约与场景结果；标志元素：水平服务路线、圆形节点和区域微注。
- HTML实现:以语义 section、CSS Grid 和少量 CSS 线条构成路线；复杂跨区域依赖才使用 Mermaid，地图或现场照片只使用用户提供且有权使用的真实素材。手机端路线转为纵向节点，按城市/场景顺序展开，不缩小标签或强留横向地图；没有素材时用区域清单、真实指标和交付条件替代，不伪造地理图或客户分布。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，节点/日期使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：IBM Plex Sans / DIN；以系统无衬线实现。
