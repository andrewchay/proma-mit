# 时间锚点叙事 Time Anchor Narrative (年份锚点×叙事停顿)
> 用户展示名：浅色 · 信号黄标记的年度时间线汇报
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 演示 deck · 中性派 `中性·还原94%`

- 参考:年度发布会、成长叙事片头、战略会时间章节；继承演讲中的推进与停顿，不做静态甘特图或密集项目控制页。
- 适配:路演、年度会、全员会、经营回顾、公司发展叙事与发布会；适合内容有清晰过去、当前转折、未来节点，且需由演讲者带领观众逐页前进的 10—25 页 deck。选择它而非 Milestone Control Room，当重点是演讲的时间感与集体共识，而不是实时状态追踪。
- 视觉DNA:配色=暖白#FBFAF5、墨黑#1D1E1C、信号黄#EFDA2D、规则灰#D1D0C9；字体=中文无衬线大标题、等宽月份与页码；母版=①年份/阶段封面②单一时间锚点页③四节点行动页④深色叙事停顿页⑤下一阶段收束页；标志元素：超大年份、黄色“现在”锚点、深色共识页。
- HTML实现:使用 Reveal 1440×810 和统一 `.slide-content`，标题≥48px、正文≥20px、节点/来源≥16px；时间节点用原生 HTML 阶段条，真实趋势/比较才加载 Chart.js。深色页只用于一句判断的停顿，明确设置浅色正文和高对比度；不使用渐变、霓虹和满页装饰。没有可靠时间数据时，以已发生事实和下一步行动替代伪精确时间线。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，年份/月度/页码使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Helvetica Now / Inter；以系统无衬线实现。
