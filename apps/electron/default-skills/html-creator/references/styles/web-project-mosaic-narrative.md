- 参考:项目共建页面、城市计划视觉、现代品牌项目介绍；迁移不同项目事实之间的拼版节奏，不使用复古剪贴、孟菲斯符号或假摄影。
- 适配:联合项目、城市计划、客户共建、品牌项目、社会议题 campaign 与开放申请页；适合项目由覆盖范围、阶段、参与者和下一步共同构成的内容。选择它而非 Case Study Evidence Scroll，当页面需要让外部读者参与一个仍在展开的项目，而不是回顾一段已经结束的案例。
- 视觉DNA:配色=暖白#F7F5F0为首屏与阅读基底+钴蓝#3159E8（项目总览）、信号黄#F1CE2C（参与步骤）、珊瑚红#EF5B3E（项目节点）、深墨#171716（邀请/收束）；字体=中文无衬线标题、等宽项目编号；布局=首屏用不等比例蓝黄红项目事实拼版建立范围，中段以参与路径而非普通时间线组织内容，末段以深色邀请页引出申请或合作行动；标志元素：事实拼版、四步参与路径、深色邀请收束。
- HTML实现:CSS Grid 用于项目事实的非等比例组合，颜色块承载明确数字或短句而非装饰；真实项目图可作为一个切面插入，无图时使用范围、阶段、参与条件与成果替代。移动端拼版转为总览→事实→路径→邀请的单列，确保每块都有可独立理解的语义；避免图片拼贴、动态贴纸、手绘元素和过量阴影。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，项目/阶段编号使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Inter / Helvetica Neue；以系统无衬线实现。
