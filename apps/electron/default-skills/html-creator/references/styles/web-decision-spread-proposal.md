# 轻量双页提案 Decision Spread Proposal (判断左页×证据右页)
> 用户展示名：浅色 · 钴蓝点缀的方案说明页
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原95%`

- 参考:策略提案双页 / 高级咨询执行摘要 / 产品决策备忘录；保留“每一章节是一组判断与证据”的读法，不复刻任何文档品牌样式。
- 适配:项目说明、方案提案、投标材料、客户立项、产品改版说明与决策会预读；适合一个主张需要对应一组事实、约束和负责人，且页面常被导出 PDF 或在会议前阅读。选择它而非 Split-Screen Product Narrative，当左右并置承担的是决策与证据，而不是产品功能与界面演示。
- 视觉DNA:配色=雾白#F8F7F2、墨黑#212221、钴蓝#2456D8、边线灰#D3D2CB；字体=全程中文无衬线，判断句用 650 字重，正文保持 1.8 行高，编号等宽；布局=每个章节是左侧“问题/判断”、右侧“证据/约束”的双页，页面节奏在摘要、实施步骤、决策请求之间切换，蓝色仅标记行动、时间节点与负责人；标志元素：双页分割线、决策请求条。
- HTML实现:用 CSS Grid 实现并列内容，背景舞台与内容容器拆层；主张与数据各自保留独立阅读宽度，量化关系使用 Chart.js，行动计划用原生 2—4 步阶段条。手机端严格按判断→证据→实施→负责人→决策请求堆叠，禁止保留两列后缩小字体；没有可信数据时只呈现已知约束和待验证假设，不伪造 KPI。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，编号/日期使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Inter / Arial Grotesk；以系统无衬线实现。
