# 经营节奏看板 Operating Rhythm Board（周期指标+风险队列+行动面）
> 用户展示名：浅色 · 荧光黄点缀的经营进度看板
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原96%`

- 参考:F1 Live Timing / Bloomberg Terminal / Shopify 管理界面；实时播报感与管理者摘要的融合
- 适配:周报、月报、季度总结、经营复盘、交付状态板；适合在一页中同时读到数字、风险、负责人和下一动作。
- 视觉DNA:配色石墨黑#111111+冷白#F4F4F1+荧光黄#D8FF00+信号红#FF3B30，黄表示进行、红仅表示风险。字体压缩数字×等宽标签。布局顶部周期与 KPI 横条，中部行动队列，底部趋势/注释/来源。标志元素：稳定数字对齐、下三分之一播报条、风险不藏在卡片里。
- HTML实现:Tailwind Grid/Flex，数字启用 `tabular-nums`；量化趋势用 Chart.js canvas，状态由语义文字和颜色双重表达。静态交付中更新时间必须来自给定素材，不模拟实时请求；手机端 KPI 横滑、行动队列改单列，保留负责人和下一步。
- 字体映射：默认使用系统字体栈实现。参考气质：DIN Condensed / IBM Plex Mono，映射为 Arial Narrow + ui-monospace。
