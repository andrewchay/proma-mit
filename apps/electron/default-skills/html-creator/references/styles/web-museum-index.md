# 博物馆索引 Museum Index（编号目录+稀疏元数据+作品队列）
> 用户展示名：浅色 · 馆标红点缀的档案目录页
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 安静派 `安静·还原88%`

- 参考:Vitra Design Museum 数字档案 / The New Museum Archive / Walker Art Center；馆藏检索卡与展签排印
- 适配:文化机构、档案项目、藏品库、研究成果、建筑/设计作品集；适合条目众多、需要可靠检索感与策展节奏的页面，而非以瀑布流图片取胜的画廊。
- 视觉DNA:配色馆藏白#F8F7F3+墨黑#171717+档案灰#8B8B86+馆标红#B5252A，红只标记当前章节和索引状态。字体克制无衬线，作品编号与年代使用等宽数字。布局固定目录栏＋主列作品队列，每件以“编号/题名/年代/媒介/一句注释”成行，图片只占少量精选条目。标志元素：连续藏品号、窄幅馆藏标签、细线与大段无图留白。
- HTML实现:原生语义列表或 Tailwind Grid 实现 `aside` 粘性目录与可筛选的锚点索引；细分隔线、`font-variant-numeric: tabular-nums` 和 CSS counter 产生档案秩序。手机端将目录折叠为横向章节导航，条目保持单列；若无真实作品图，以文字展签和尺寸比例占位，不能模拟馆藏实拍，因此图像叙事降级。
- 字体映射：默认使用系统字体栈实现。参考气质：Helvetica Neue / Univers（馆藏无衬线）+ IBM Plex Mono，映射为 system-ui + ui-monospace。
