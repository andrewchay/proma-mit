# 品牌叙事图谱 Narrative Brand Atlas（章节主张+证据岛+品牌坐标）
> 用户展示名：浅色 · 暖白蓝企业故事长页
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原93%`

- 参考:Apple 产品叙事页 / Monocle 品牌报道 / Airbnb 年度故事；长篇品牌编辑与产品网页的节奏结合
- 适配:公司介绍、业务线介绍、品牌主页、capability showcase；适合需要先建立“为何存在”再证明能力的企业内容。
- 视觉DNA:配色暖白#F4F1EA+墨黑#181817+品牌蓝#2457F5+雾灰#D1CDC2，蓝只用于章节坐标与行动。字体紧凑无衬线主张×等宽索引。布局每屏一个判断、交替出现证据岛/客户成果/业务地图，页边有连续章节编号。标志元素：叙事坐标轴、主张与事实的交替呼吸。
- HTML实现:Tailwind Grid + `scroll-snap` 可选增强，主张 section 用大字号和留白，证据岛用真实数字/用户素材；无照片时以地图、数据和 SVG 图形替代，不编造客户。手机端坐标轴变为顶部进度条，证据按叙事顺序堆叠；静态版可高还原。
- 字体映射：默认使用系统字体栈实现。参考气质：Inter / SF Pro + Geist Mono，映射为 system-ui + ui-monospace。
