# 业务标本目录 Business Specimen Index (编号对象×使用边界)
> 用户展示名：浅色 · 深绿点缀的编号服务目录
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 中性派 `中性·还原93%`

- 参考:工业设计规格册 / 服务设计工具箱 / 现代产品资料目录；迁移“对象可比较、边界可查阅”的信息组织，不使用复古纸张或陈列摄影。
- 适配:capability showcase、服务介绍、产品功能集、解决方案目录、团队方法说明；适合内容由 4—12 个明确对象构成，且用户需要理解每项能力的输入、输出、适用条件与组合关系。选择它而非 Capability Proof Grid，当任务是让读者像查目录一样浏览和比较能力，而不是沿一条证据链被说服。
- 视觉DNA:配色=纸白#FFFEFA、深绿#1F5544、炭黑#171716、规则灰#D3D2CB；字体=中文无衬线主标题×等宽编号与字段，标题不使用英文宽字距；布局=总目录引入后按 A-01、A-02 等编号展开，每个对象采用不等高“规格、使用场景、适用边界、结果”单元，避免等宽卡片矩阵；标志元素：超大目录编号、规格线与边界说明。
- HTML实现:以 12 列 CSS Grid 和 `article` 目录项组织内容，字段标签使用系统等宽字体，必要的能力关系用 Mermaid 或简洁连线表达；真实产品截图可做局部证据，缺图时使用输入—判断—输出结构和案例数字替代。手机端先显示名称、适用场景和结果，再展开规格与边注；避免横向压缩表格，所有对象回到单列阅读。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，编号/参数使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Neue Haas Grotesk / IBM Plex Sans；以系统无衬线实现。
