# 轻底数据年鉴 Operating Data Almanac (年度章节×单结论图)
> 用户展示名：浅色 · 砖橙点缀的经营数据年鉴
> 静态呈现限制：禁止跑马灯、自动轮播、自动滚动内容条和循环滚动展示。


> 网页 · 安静派 `安静·还原93%`

- 参考:现代经营年报 / 数据新闻的图注体例 / 投资者信的年度章节；迁移“变化—解释—含义”的阅读节奏，避免做成后台仪表盘或暖白纸媒。
- 适配:周月报、季度总结、年度经营回顾、行业观察、数据报告与高管预读；适合已有时间口径、可比较指标和少量方法说明的内容。选择它而非 Editorial Data Observatory，当读者最需要连续理解经营变化与管理含义，而非深入研究样本或方法本身。
- 视觉DNA:配色=冷灰白#F5F4EF、碳黑#292A28、砖橙#D84826、刻度灰#BDBDB5；字体=中文无衬线结论标题、等宽数据与来源行，正文不使用衬线；布局=年度/季度章节引入后，一页只给出一个结论式图题、一张真实量化图和一段经营解释，账本页以轻线表收束关键指标；标志元素：超大年份、图表下方的可读图注与口径行。
- HTML实现:时间、比较和构成关系必须使用 Chart.js canvas，明确单位、范围、来源和不可比限制；无真实数据时退为定性阶段图或待补数据位，禁止 CSS 柱图伪造趋势。桌面端保留结论主列与方法侧注，手机端将方法移动到图表后并保持图表最小可读高度；不使用渐变、大面积深底或仪表盘式密集 KPI。
- 字体映射：默认使用 `PingFang SC, Microsoft YaHei, Noto Sans CJK SC, system-ui, sans-serif`，数字/口径使用 `ui-monospace, SFMono-Regular, Menlo, monospace`。参考气质：Inter / IBM Plex Sans；以系统无衬线实现。
