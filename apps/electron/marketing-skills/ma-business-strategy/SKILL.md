# MA Business Strategy — 业务诊断与战略分析引擎

## 定位

本 Skill 是 Proma Agent 的**实体业务战略分析层**，专注于本地生活/零售/餐饮/快消等实体业务的深度诊断和战略规划。与 `ug-analysis`（通用数据分析）、`game-strategy`（游戏行业战略）、`growth-scout`（增长机会发现）形成互补：

```
Proma Agent
├── ug-analysis → 通用数据分析方法论（对比/因果/拆解原则）
│       ↓
├── ma-business-strategy（本层）→ 实体业务战略分析（诊断/组合/竞争/增长）
│       ↓
├── game-strategy → 游戏行业战略框架（五力/蓝海/对齐）
│       ↓
├── growth-scout → 增长机会发现与实验设计
│       ↓
└── 工作区产物（strategy-report / 执行计划）
```

## 核心分析框架

### 框架一：业务健康度诊断（Business Health Check）

**四维诊断模型**：

| 维度 | 核心指标 | 诊断要点 |
|------|---------|---------|
| **营收质量** | 客单价、复购率、营收集中度 | 高客单价是否可持续？营收是否过度依赖少数 SKU？ |
| **利润结构** | 毛利率、损耗率、履约成本 | 哪些 SKU 是利润引擎？哪些是亏损引流？ |
| **运营效率** | 时段分布、距离分布、人效 | 是否存在闲置时段？配送半径是否合理？ |
| **增长潜力** | 新客获取、场景拓展、品类延伸 | 当前增长是流量驱动还是场景驱动？ |

**诊断输出**：业务健康度评分卡（0-100 分）+ 关键风险清单

### 框架二：产品组合分析（Product Portfolio Analysis）

**四象限矩阵**（销量 × 毛利率）：

```
高毛利
  │
  │  💎 潜力产品      🌟 明星产品
  │  （低销量高毛利）  （高销量高毛利）
  │  → 加大曝光       → 保持放大
  │
  │  ❌ 问题产品      💰 引流产品
  │  （低销量低毛利）  （高销量低毛利）
  │  → 优化或淘汰     → 提毛利或转引流
  │
  └──────────────────────────────
       低销量              高销量
```

**分析步骤**：
1. 计算每个 SKU 的：销量、营收、毛利、毛利率、营收贡献占比
2. 以销量中位数和毛利率中位数为分界线划分四象限
3. 识别各象限的 actionable insights
4. 输出 SKU 调整建议（保留/放大/优化/淘汰）

**价格带分析**：
- 将 SKU 按价格带分组（<¥30, ¥30-50, ¥50-80, ¥80-100, >¥100）
- 分析各价格带的：产品数、销量、营收、毛利率
- 识别"黄金走量带"和"高价值带"

### 框架三：竞争战略分析（Competitive Strategy）

**波特五力模型**（实体业务适配）：

| 力量 | 实体业务关键问题 |
|------|----------------|
| 现有竞争 | 同品类竞争者数量、差异化程度、价格战风险 |
| 新进入者 | 开店门槛、供应链壁垒、品牌认知门槛 |
| 买方议价 | 转换成本、价格敏感度、品质要求 |
| 供应商议价 | 优质货源稀缺性、采购规模、替代供应商 |
| 替代品 | 相邻品类竞争（如奶茶 vs 果切）、自制替代 |

**竞品对标表**：
| 竞品 | 核心优势 | 本业务应对策略 |
|------|---------|---------------|
| 竞品A | ... | ... |
| 竞品B | ... | ... |

### 框架四：战略定位与蓝海（Blue Ocean Strategy）

**ERRC 四行动框架**（实体业务适配）：

| 行动 | 问题 | 实体业务典型应用 |
|------|------|----------------|
| **Eliminate** 消除 | 哪些被行业视为理所当然的因素应消除？ | 低毛利 SKU、价格战、过度包装 |
| **Reduce** 降低 | 哪些因素应降到行业标准以下？ | SKU 数量、门店面积、功能宣传 |
| **Raise** 提升 | 哪些因素应远超行业标准？ | 品质背书、场景体验、服务标准 |
| **Create** 创造 | 哪些行业从未提供的因素应创造？ | 情绪价值、社交属性、数字化信任 |

**价值曲线**：
- 低于竞品：SKU 丰富度、绝对低价、门店密度
- 持平竞品：品质、配送速度
- 远超竞品：客单价、毛利率、场景适配
- 全新创造：情绪价值、社交礼赠、数字化背书

### 框架五：战略对齐检验（Gaddis Ends-Means Alignment）

**狐狸-刺猬矩阵**：
| | 固定目标 (Hedgehog) | 灵活目标 (Fox) |
|---|---------------------|----------------|
| **固定手段** | 僵化但聚焦 | 混乱 |
| **灵活手段** | **大战略家** (目标坚定，执行灵活) | 机会主义，无方向 |

**三大错位诊断**：
1. **定位 vs 履约错位**：高奢定位但基建/标准化不足
2. **目标 vs 资源错位**：利润最大化但 SKU 臃肿、供应链弱
3. **正面 vs 侧翼错位**：与巨头正面竞争但未放大侧翼优势

### 框架六：增长机会发现（RICE 评分）

**Metric Tree 拆解**：
```
营收 = 订单量 × 客单价
  ├─ 订单量 = 新客订单 + 复购订单
  │    ├─ 新客 = 流量 × 转化率
  │    └─ 复购 = 存量用户 × 复购率
  └─ 客单价 = 件单价 × 件数
       ├─ 件单价 = 产品组合 + 加价率
       └─ 件数 = 连带率 + 加购率
```

**RICE 评分公式**：
```
RICE = (Reach × Impact × Confidence) / Effort
```

| 因子 | 说明 | 评分标准 |
|------|------|---------|
| Reach | 影响用户数/订单数 | 月订单量影响 |
| Impact | 对核心指标的影响 | 高=3, 中=2, 低=1 |
| Confidence | 成功概率 | 高=100%, 中=80%, 低=50% |
| Effort | 投入成本 | 人月 |

## 分析工作流

### Step 0: 数据准备与清洗

**输入数据类型**：
| 数据类型 | 格式 | 用途 |
|---------|------|------|
| 订单数据 | Excel/CSV | 时段分析、距离分析、客单价分布 |
| 产品数据 | Excel/CSV | SKU 分析、毛利率计算、四象限 |
| 成本数据 | Excel/CSV | 真实毛利、损耗分析 |
| 外部情报 | Markdown/YAML | 竞品分析、市场趋势 |

**数据清洗要点**：
1. 统一数据口径（订单表 vs 产品表的销量差异）
2. 处理缺失值（成本缺失的 SKU 单独标注）
3. 识别异常值（如人工费用过高的 SKU）
4. 计算衍生指标（毛利率、营收贡献、集中度）

### Step 1: 业务健康度诊断

运行诊断脚本：
```bash
python3 <skill>/scripts/business_health_check.py \
  --orders <orders_file> \
  --products <products_file> \
  --output <workspace>/diagnosis/health-check.json
```

输出：健康度评分卡 + 关键风险清单

### Step 2: 产品组合分析

运行四象限分析：
```bash
python3 <skill>/scripts/product_quadrant.py \
  --products <products_file> \
  --output <workspace>/diagnosis/quadrant-analysis.json
```

输出：四象限分类 + SKU 调整建议

### Step 3: 竞争战略分析

基于外部情报（可用 `game-intelligence` 或浏览器搜索获取）：
1. 识别主要竞品（3-5 个）
2. 完成五力分析
3. 完成竞品对标表
4. 识别蓝海机会（ERRC）

### Step 4: 战略对齐检验

检查三大错位：
1. 定位 vs 履约
2. 目标 vs 资源
3. 正面 vs 侧翼

输出：对齐度评分 + 调整建议

### Step 5: 增长机会发现

1. Metric Tree 拆解
2. 生成机会池（16+ 个机会）
3. RICE 评分排序
4. 输出 Top 5 机会 + 实验设计

### Step 6: 综合报告生成

整合所有分析，生成：
- `strategy-report.md`（完整战略报告）
- `executive-summary.html`（高管摘要 PPT）
- `action-plan.md`（90 天执行计划）

## 质量检查清单

在输出战略报告前确认：

- [ ] 数据口径是否统一？（订单表 vs 产品表）
- [ ] 四象限分析是否基于真实数据？（而非模板）
- [ ] 竞争分析是否引用了具体竞品？（而非泛泛而谈）
- [ ] 增长机会是否有 RICE 评分？（可排序）
- [ ] 执行计划是否有明确里程碑？（30/60/90 天）
- [ ] 风险是否有分级和 mitigation？（高/中/低）
- [ ] 报告是否已保存为 Markdown/HTML？

## 示例对话

### 示例 1: 鲜果切业务诊断

**用户**: "帮我分析一下这个鲜果切外卖业务，订单数据和产品成本在附件里"

**Agent**:
1. 读取订单数据和产品数据，清洗并计算衍生指标
2. 运行业务健康度诊断 → 发现客单价高但 SKU 臃肿
3. 运行四象限分析 → 发现芒果系列是利润引擎，蜜瓜是亏损引流
4. 搜索竞品情报 → 识别百果园、鲜丰、切果NOW 为主要竞品
5. 完成五力分析 + ERRC 蓝海战略
6. 进行战略对齐检验 → 发现"高奢定位 vs 草台履约"错位
7. Metric Tree 拆解 + RICE 评分 → Top 5 增长机会
8. 生成综合报告 + 90 天执行计划

### 示例 2: 咖啡店市场进入

**用户**: "我想在上海开一家精品咖啡店，帮我做个商业计划"

**Agent**:
1. 收集用户输入：预算、目标客群、差异化定位
2. 搜索上海咖啡市场情报 → 竞争密度、租金水平、消费趋势
3. 五力分析 → 现有竞争极高、替代品威胁高
4. ERRC 分析 → 消除"第三空间"概念、创造"咖啡+轻食+办公"复合场景
5. 战略对齐检验 → 预算是否匹配目标？
6. 生成商业计划书框架
