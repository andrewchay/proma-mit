# 品牌 DNA 提取

## 这个 Skill 做什么

基于提供的品牌资料，系统性地提取品牌 DNA。**必须全量覆盖以下 14 项字段，不允许只写其中一部分**（只做诊断层或只做情感层都视为未完成）。

**传承层**
- **品牌传承**（heritage）：创立背景、发展历程、里程碑事件，以及可继承的文化资产（不只是成立时间）

**需求层**
- **用户需求**（user_need）：用户真实处境与矛盾，须引用 user-analysis 的洞察，不能只写人群标签

**事实层**
- **产品/服务**（products）：核心产品线、功能卖点、价格带、SKU 结构，以及过往 campaign / slogan 等现有传播资产
- **品牌阶段**（stage）：起步期 / 成长期 / 成熟期 / 焕新期，并给出判定依据
- **产品现状**（product_status）：产品力、供应链、价格带的现状诊断，指出结构性短板与优势

**诊断层**
- **核心问题**（core_problem）：认知问题 / 转化问题 / 口碑问题，并说明界定理由
- **核心目标**（core_goal）：首要目标（曝光 / 破圈拉新 / 转化）及优先级

**价值层**
- **核心价值**（core_values）：消费者能直接感知的产品/功能价值，不是企业价值观
- **附加价值**（added_values）：情感、文化、生活方式层面的价值，具体到场景与心理收益
- **独占性来源**（uniqueness_assets）：品牌真正独有、花钱难以复制的资产（原研/工艺/艺术家合作/审美体系/供应链/社群等），以及把它大众化的路径——独特是壁垒，普遍是生意，二者的平衡决定品牌能走多远
- **情绪价值定位**（emotional_value）：品牌溢价中来自情绪的部分——购买它在满足"存在感"（身份/圈层表达）还是"满足感"（功能回报），以及品牌追求的消费者状态（如平静、热爱、庆祝）

**人格层**
- **品牌人格**（personality_traits）：3-5 个有画面感的形容词
- **品牌语气**（tone_of_voice）：具体到语言风格的一句话描述

**定位层**
- **差异化优势**（differentiator）：结合市场/竞品/用户分析的核心差异点，并说明为何竞品难以复制

## 何时使用

**合适的场景：**
- 品牌策略制定或品牌焕新项目
- 新产品上市前的品牌诊断
- 品牌与竞品差异化梳理
- 品牌内容创作前的调性校准
- 品牌联名或跨界合作前的匹配评估

**不合适的场景：**
- 已有明确品牌手册且无需更新的日常执行
- 纯战术层面的单次内容创作（不需要深度品牌分析）

## 工作流

### Step 1 · 资料收集

向用户收集以下信息（如果缺失则标注为「待补充」）：
| 信息项 | 说明 |
|--------|------|
| 品牌历史 | 创立背景、发展历程、里程碑事件 |
| 产品/服务 | 核心产品线、功能卖点、价格带 |
| 目标人群 | 现有客群画像、理想客群 |
| 品牌愿景 | 品牌使命、长期目标 |
| 视觉资产 | Logo、包装、视觉风格描述 |
| 现有传播 | 过往 campaign、slogan、核心文案 |
| 竞品对标 | 直接竞品和 aspiration 品牌 |

### Step 2 · DNA 提取

基于收集的资料，按 14 项字段做系统分析。

> **工作流/生成到 `brand-dna/` 目录的上下文中，必须将分析落盘为三个 Markdown 文件保存到 `brand-dna/` 目录**（校验会精确检查文件名）：
> - `brand-dna.md` — 品牌传承、用户需求、产品/服务、核心价值、附加价值、独占性来源、情绪价值定位、品牌人格、品牌语气
> - `brand-diagnosis.md` — 品牌阶段、产品现状、核心问题、核心目标
> - `differentiation.md` — 差异化优势
>
> 落盘正文必须明示并用精确措辞：
> - `## 品牌传承`：正文含「传承」「历史」「创立」「发展」「里程碑」等词
> - `## 用户需求`：正文含「需求」「痛点」「处境」「矛盾」「洞察」等词
> - `## 产品/服务`：正文含「产品」「服务」「功能」「卖点」「价格」「价格带」「产品线」等词
> - `## 品牌阶段`：正文含「起步期」「成长期」「成熟期」「焕新期」「阶段」等词
> - `## 产品现状`：正文含「产品力」「供应链」「价格带」「SKU」「产品诊断」等词
> - `## 核心问题`：正文含「认知问题」「转化问题」「口碑问题」「问题」等词
> - `## 核心目标`：正文含「目标」「优先级」「曝光」「破圈」「拉新」等词
> - `## 独占性来源`：正文含「独占」「独特」「难以复制」「壁垒」「大众化」等词
> - `## 情绪价值定位`：正文含「情绪价值」「存在感」「满足感」「圈层」等词
> - `## 核心价值` / `## 附加价值` / `## 品牌人格` / `## 品牌语气` / `## 差异化优势` 同样保持小标题精确
>
> 每个文件正文不少于 300 字。

### Step 3 · 验证与校准

向用户确认提取结果是否准确，特别是：
- heritage 是否挖掘到足够深的文化根源
- personality_traits 是否是团队公认的品牌人格
- differentiator 是否真正区别于竞品
- 核心问题是否真的由前面分析推导得出，而不是主观设定
- 用户需求是否引用了用户分析结论，而不是泛化标签

## 规则

1. **heritage** 要挖掘品牌的历史根源和文化传承，不只是成立时间
2. **user_need** 必须写用户的真实处境与矛盾，不能只写"25-35 岁女性"这类标签；有用户分析资料时必须引用其洞察
3. **products** 要覆盖产品线、卖点、价格带、SKU 与现有传播资产，缺一项即不完整
4. **stage / product_status / core_problem / core_goal** 是诊断层，必须由前面的事实推导得出，不能主观设定；四者缺一即视为未完成
5. **core_values** 是消费者能直接感知的产品/功能价值，不是企业价值观
6. **added_values** 是情感、文化、生活方式层面的价值，要具体到场景
7. **personality_traits** 用3-5个形容词，避免空泛（如"优秀的""专业的"），要有画面感
8. **tone_of_voice** 要具体到语言风格，如"像一个懂行但不炫耀的朋友"
9. **differentiator** 必须说明"为什么竞品难以复制"，只写差异不提不可复制性不算完成
10. 如果资料不足，**status** 标记为 `partial` 并列出 **missing_fields**——但诊断层四项不允许以"资料不足"为由跳过，至少要给出基于现有资料的判断与置信度
11. **confidence_score** 基于信息充分程度打分（0-100），诚实评估
12. **uniqueness_assets 只列"花钱难复制"的资产**：能被竞品用预算直接对齐的不算独占性（如明星代言、常规投放）；判断标准是"如果竞品出三倍预算，它还能不能被复制"
13. **uniqueness_to_mass_path 必须可执行**：说明独特资产如何规模化触达大众（生产、渠道、人群扩展），只写"保持独特"不写路径视为未完成
14. **emotional_value 要区分存在感与满足感**：身份/圈层表达是存在感，功能/物质回报是满足感；并给品牌追求的消费者状态一个词定位（如平静、热爱、庆祝），它是创意与内容调性的锚
