# 达人内容五维审核

从合规、品牌契合、内容质量、品牌形象一致性、数据可验证性五个维度系统审核文字内容（与 ContentAuditService 的五维评分体系对齐），输出结构化评分与可操作的修改建议。

## 何时使用

**合适的场景：**
- 达人稿件/脚本/文案的文字审核（ma-draft-review 调用）
- 品牌方对达人内容的内容质检
- 投放前的合规性把关
- 内容修改后的二次审核

**不合适的场景：**
- 图片/视频画面审核 → 用 `ma-image-audit`
- 内容创意方向的早期讨论 → 用 `ma-creative-concept`
- 没有具体审核内容时

## 调用协议

**输入**（由调用方提供）：
- 稿件全文（标题/正文/标签）
- brief 上下文（可选）：该达人 brief 或品牌通用要求，用于品牌契合度对照
- 审核口径（可选）：字数要求、关键标签等归一化口径；未提供时按下方"审核口径"默认规则执行

**输出**：JSON，供调用方组装为最终回复：

```json
{
  "compliance": { "score": 90, "issues": ["问题"], "suggestions": ["建议"] },
  "brand_alignment": { "score": 75, "issues": [], "suggestions": [] },
  "quality": { "score": 80, "issues": [], "suggestions": [] },
  "brand_image": { "score": 82, "tone_match": "调性匹配度说明", "persona_alignment": "人格匹配说明", "issues": [], "suggestions": [] },
  "data_verifiability": { "score": 70, "insight_support": "事实/数据来源支撑说明", "issues": [], "suggestions": [] },
  "issues": [
    { "location": "图片1/开头/结尾/标题/正文", "issue": "问题描述", "suggestion": "修改建议", "severity": "critical | warning" }
  ],
  "overall_score": 82,
  "has_critical": false
}
```

- `issues` 为跨维度合并后的逐条问题，`location` 必须带位置锚点，按严重度排序（critical 在前）
- `severity`：**critical = 硬伤**（合规违规 / 核心信息错误 / 内容方向偏离 brief 核心概念 / 关键话题标签缺失 / 达人人设与品牌调性严重冲突）；**warning = 建议**（轻微瑕疵、可优化点），缺省 warning
- `has_critical`：任一 issue 为 critical 时为 true；调用方（ma-draft-review）据此判红卡
- `score` / `overall_score` 仅作内部参考，**不用于调用方红黄判定**；`overall_score` = 合规×0.20 + 品牌契合×0.25 + 质量×0.25 + 品牌形象×0.20 + 数据可验证×0.10（与 ContentAuditService 加权一致）

## 工作流

### Step 1 · 确认输入
确认稿件全文与 brief 是否齐备；缺 brief 时注明"按通用要求审核"，照常评分。

### Step 2 · 五维审核

| 维度 | 权重 | 检查要点 |
|------|------|---------|
| 合规性 | 20% | 敏感词、平台规范、广告法（极限词/虚假宣传/特殊品类）、品牌安全，**一票否决** |
| 品牌契合度 | 25% | 结合 brief：内容方向、文案卖点、核心承诺（Key Message）传达、**存在感传递**、**品牌语言一致性**、CTA 明确性 |
| 内容质量 | 25% | 结构、逻辑、可读性、互动性、信息密度（事实陈述 vs 空洞形容词）、**SUCCESs 黏性检查**（简单/意外/具体/可信/情感/故事，见规则 5） |
| 品牌形象一致性 | 20% | **调性一致性**（语言风格 vs 品牌人格）、**人格匹配**（达人表达 vs 品牌「角色设定」）、视觉合规提示（有视觉规范时）；奥格威原则：「品牌形象是一项长期投资」——每条内容都是品牌资产的累积 |
| 数据可验证性 | 10% | **事实/数据有来源支撑**（非编造数字）、**创意可拆解为可测试变量**（标题/封面/开头/CTA）、有历史 Benchmark 可对标时给出对标说明；奥格威原则：「调查是广告创作的基础，而非创意的敌人」 |

> 品牌形象一致性与数据可验证性依赖调用方提供品牌人格/视觉规范/数据支撑：**有则对照审核，未提供时在对应维度注明"未提供品牌规范/数据支撑，按内容内在一致性评估"**，不虚构标准、不因此降权跳过。

### Step 3 · 评分与输出

每维度 0-100 分（内部参考），`overall_score` 按五维加权（合规 20% / 品牌契合 25% / 质量 25% / 品牌形象 20% / 数据可验证 10%）；问题逐条列出并标注 `severity`，给出可操作建议（附修改示例），输出 JSON。

## 审核口径（归一化，优先于 brief 旧措辞）

1. **字数**：仅参考不计分——**不按 brief 字数要求（如 300 字），不强制扩充**；差异明显时可并入"总体建议"温和提示，不进入 issues、不标 critical
2. **关键词埋点**：正文语义体现即达标，支持模糊查询，不强求标题/前 15 字
3. **话题标签**：关键标签必须植入（具体标签由调用方口径提供），缺失时对应 issue 标 **critical**
4. 调用方提供的 brief 中旧措辞（如 300 字 / ≤5 标签 / 前 15 字）与本口径冲突时，以本口径为准

## 规则

1. **合规一票否决**：严重违规直接标 critical，`has_critical` = true
2. **品牌契合关注核心信息传递**：重点检查产品卖点是否准确、品牌调性是否被冲淡；内容方向偏离 brief 核心概念（正文主体未承载 brief 核心逻辑，仅标题沾边不算）标 critical
3. **存在感传递与品牌语言按 warning 级把关**：种草类内容若通篇只有功能描述、没有任何身份想象或晒单钩子（"想拥有/想晒出来"的情绪触点），记 warning 并给改法；品牌语言方面，误用昵称/系列名、圈层用语不符合品牌语境同样记 warning——这两项是种草深度的放大器，缺了不判 critical，但出现错误用法必须指出
4. **调性严重冲突才 critical**：品牌形象一致性维度中，仅当达人人设与品牌调性严重冲突（如高端护肤 × 搞笑剧情博主）或出现与品牌形象冲突的硬性画面时标 critical；调性轻微偏差归 warning 并给出人格卡对照建议
5. **数据可验证性按 warning 级把关**：内容中的具体数字/实验结论无来源支撑时记 warning 并建议补充出处；无中生有涉及功效宣称的归入合规性判 critical
6. **内容质量维度含 SUCCESs 黏性检查（warning 级）**：①简单——核心信息一句话能复述，还是被三个卖点稀释；②意外——有无打破预期的钩子（好奇缺口）；③具体——用感官细节/具体场景，不用抽象形容词；④可信——有可验证的细节支撑；⑤情感——讲"一个人"的故事而非泛泛的"大家"（个体>群体）；⑥故事——信息是否包在叙事里。另查**知识的诅咒**：品牌方术语（成分名/工艺名/内部黑话）未翻译成用户语言时记 warning 并给口语化改法——审核者懂≠读者懂，按击拍者实验（以为传到 50%、实际 2.5%）从严把关
7. **问题要具体**：每条 issues 带位置锚点、severity 与修改建议，不笼统说"创意一般"；硬伤不标 warning、轻微不标 critical
8. **平台规范差异化**：按平台规则检查（小红书种草感、抖音前 3 秒钩子等）
9. **保持客观**：不因达人粉丝量大小放宽标准
