# 达人内容三维审核

从合规、品牌契合、内容质量三个维度系统审核文字内容，输出结构化评分与可操作的修改建议。

## 何时使用

**合适的场景：**
- 达人稿件/脚本/文案的文字审核（ma-draft-review 调用）
- 品牌方对达人内容的内容质检
- 投放前的合规性把关
- 内容修改后的二次审核

**不合适的场景：**
- 图片/视频画面审核 → 用 `ma-image-audit`
- 内容创意方向的早期讨论 → 用 `ma-creative-concept`
- 没有具体审核内容时

## 调用协议

**输入**（由调用方提供）：
- 稿件全文（标题/正文/标签）
- brief 上下文（可选）：该达人 brief 或品牌通用要求，用于品牌契合度对照
- 审核口径（可选）：字数要求、关键标签等归一化口径；未提供时按下方"审核口径"默认规则执行

**输出**：JSON，供调用方组装为最终回复：

```json
{
  "compliance": { "score": 90, "issues": ["问题"], "suggestions": ["建议"] },
  "brand_alignment": { "score": 75, "issues": [], "suggestions": [] },
  "quality": { "score": 80, "issues": [], "suggestions": [] },
  "issues": [
    { "location": "图片1/开头/结尾/标题/正文", "issue": "问题描述", "suggestion": "修改建议", "severity": "critical | warning" }
  ],
  "overall_score": 82,
  "has_critical": false
}
```

- `issues` 为跨维度合并后的逐条问题，`location` 必须带位置锚点，按严重度排序（critical 在前）
- `severity`：**critical = 硬伤**（合规违规 / 核心信息错误 / 内容方向偏离 brief 核心概念 / 关键话题标签缺失）；**warning = 建议**（轻微瑕疵、可优化点），缺省 warning
- `has_critical`：任一 issue 为 critical 时为 true；调用方（ma-draft-review）据此判红卡
- `score` / `overall_score` 仅作内部参考，**不用于调用方红黄判定**

## 工作流

### Step 1 · 确认输入
确认稿件全文与 brief 是否齐备；缺 brief 时注明"按通用要求审核"，照常评分。

### Step 2 · 三维审核

| 维度 | 检查要点 |
|------|---------|
| 合规性 | 敏感词、平台规范、广告法（极限词/虚假宣传/特殊品类），**一票否决** |
| 品牌契合度 | 结合 brief：内容方向、文案卖点、品牌调性 |
| 内容质量 | 结构、逻辑、可读性、互动性 |

### Step 3 · 评分与输出
每维度 0-100 分（内部参考），`overall_score` 取三维均分；问题逐条列出并标注 `severity`，给出可操作建议（附修改示例），输出 JSON。

## 审核口径（归一化，优先于 brief 旧措辞）

1. **字数**：仅参考不计分——**不按 brief 字数要求（如 300 字），不强制扩充**；差异明显时可并入"总体建议"温和提示，不进入 issues、不标 critical
2. **关键词埋点**：正文语义体现即达标，支持模糊查询，不强求标题/前 15 字
3. **话题标签**：关键标签必须植入（具体标签由调用方口径提供），缺失时对应 issue 标 **critical**
4. 调用方提供的 brief 中旧措辞（如 300 字 / ≤5 标签 / 前 15 字）与本口径冲突时，以本口径为准

## 规则

1. **合规一票否决**：严重违规直接标 critical，`has_critical` = true
2. **品牌契合关注核心信息传递**：重点检查产品卖点是否准确、品牌调性是否被冲淡；内容方向偏离 brief 核心概念（正文主体未承载 brief 核心逻辑，仅标题沾边不算）标 critical
3. **问题要具体**：每条 issues 带位置锚点、severity 与修改建议，不笼统说"创意一般"；硬伤不标 warning、轻微不标 critical
4. **平台规范差异化**：按平台规则检查（小红书种草感、抖音前 3 秒钩子等）
5. **保持客观**：不因达人粉丝量大小放宽标准
