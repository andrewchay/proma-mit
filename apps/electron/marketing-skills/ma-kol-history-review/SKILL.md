# 达人历史内容审阅与履约评估

## 这个 Skill 做什么

为达人合作决策提供全面的历史数据分析和风险评估：
- **内容质量分析**：近期内容质量评分、风格一致性、互动数据趋势
- **品牌合作历史**：过往合作品牌、竞品合作情况、品牌内容质量
- **履约评估**：按时交付率、修改配合度、内容合规率
- **风险预警**：数据异常、风格突变、负面信号识别

## 何时使用

**合适的场景：**
- 合作前的达人尽职调查
- 合作后的履约复盘
- 达人库定期健康检查
- 发现达人数据异常时的深度分析
- 竞品合作风险评估

**不合适的场景：**
- 达人 CRM 日常管理（用 ma-kol-crm）
- 内容创作脚本指导（用 ma-script-studio）
- 没有达人历史数据时（无法评估）

## 工作流

### Step 1 · 输入确认

确认审阅对象和目的：
| 信息项 | 说明 |
|--------|------|
| 达人ID/名称 | 需要审阅的达人 |
| 平台 | 达人主要活跃平台 |
| 审阅目的 | 合作前评估 / 合作后复盘 |
| 合作品牌 | 如涉及竞品分析，需提供品牌信息 |

### Step 2 · 内容质量分析

分析达人近期 10-20 条内容：
- 内容质量评分（基于互动率/完播率/内容完整性）
- 内容风格一致性评估
- 互动数据趋势（增长/下降/波动）

### Step 3 · 品牌合作历史与履约评估

- 过往合作品牌列表和竞品合作情况
- 按时交付率、修改配合度、内容合规率
- 识别数据异常、风格突变、负面信号等风险

## 规则

1. **竞品合作风险要具体**：近 3 月合作过直接竞品 = 高风险，6 月内 = 中风险，需明确竞品定义
2. **内容质量评分要基于客观指标**：互动率 / 完播率 / 内容完整性，不凭主观喜好打分
3. **履约评估如果没有历史数据**，标注"数据不足，建议小规模测试"，不虚构履约记录
4. **风险预警必须诚实**，不因为达人粉丝多就回避问题，负面信号要明确指出
5. **推荐结论要综合所有维度**，不是单一指标决定，需说明推荐理由
6. **brand_content_quality 判断标准**：用心 = 有创意融入/真实体验/详细展示；敷衍 = 硬广口播/画面粗糙/明显应付
7. **engagement_trend 要结合时间窗口**：近 30 天 vs 近 90 天对比，识别短期波动和长期趋势
