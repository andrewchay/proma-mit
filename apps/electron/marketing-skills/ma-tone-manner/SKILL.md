# 品牌语气调性定义

## 这个 Skill 做什么

为品牌定义系统性的语气调性规范：
- **全局调性**：跨平台一致的品牌声音和视觉方向
- **平台适配**：各平台上的语气、视觉和形式调整
- **标志性元素**：可识别的品牌资产和固定模式
- **示例文案**：体现调性的真实文案样本
- **视觉指导**：摄影、字体、图形的风格方向

## 何时使用

**合适的场景：**
- 品牌创立初期的调性定义
- 品牌焕新后的调性更新
- 多平台运营时的内容风格统一
- 品牌内容规范（Brand Content Guideline）的制定
- 新团队成员 onboarding 时的调性培训

**不合适的场景：**
- 已有详细品牌手册且团队熟悉时
- 单次内容创作（不需要系统调性定义）
- 纯视觉设计阶段（需要配合视觉设计师）

## 工作流

### Step 1 · 品牌基础确认

确认品牌 DNA 和 TA 画像是否已有：
| 信息项 | 说明 |
|--------|------|
| 品牌人格 | 3-5个形容词描述 |
| 核心价值 | 品牌承诺的关键价值 |
| TA 特征 | 目标人群的语言习惯和审美偏好 |
| 行业基准 | 同行的调性水平（避免趋同） |

### Step 2 · 调性定义

定义全局调性和各平台的适配版本。

### Step 3 · 示例与验证

生成示例文案，验证调性是否可执行、是否被目标人群接受。

## 输出格式

必须以 JSON 格式返回：

```json
{
  "status": "complete",
  "global_tone": {
    "voice_adjectives": ["真诚", "专业", "有温度"],
    "voice_description": "像一个懂行但不炫耀的朋友，专业但不居高临下",
    "visual_adjectives": ["简约", "高级", "有质感"],
    "color_direction": "低饱和中性色为主，辅以品牌accent色"
  },
  "platform_tones": {
    "小红书": {
      "voice": "真实分享感，带一点种草的热情",
      "visual": "生活化场景，自然光线，不过度修图",
      "content_format": "图文笔记为主，视频为辅",
      "dos": ["用第一人称分享真实体验", "给出具体的使用场景"],
      "donts": ["不要硬广口吻", "不要过度美化"],
      "signature_elements": ["固定的开头问候语", "特定的emoji组合"]
    }
  },
  "example_copy": {
    "小红书": "用了三周才来分享，这个精华真的救了我的换季脸。",
    "抖音": "姐妹们！这个我试过了，真的可！"
  },
  "visual_guidelines": {
    "photography_style": "自然光、生活化场景、真实感",
    "typography": "无衬线字体，标题粗体，正文常规",
    "graphic_treatment": "简洁图形，留白充足，不堆砌元素"
  }
}
```

## 规则

1. **global_tone 的 voice_adjectives 要能在所有平台保持一致**，是品牌不变的内核
2. **platform_tones 的 voice 是 global_tone 的平台适配版**，不是完全不同的调性，是同一个内核的不同表达
3. **dos 和 donts 必须具体可执行**，避免"保持一致""体现品牌"这类空话
4. **signature_elements 是可识别的品牌资产**，如特定配色、固定版式、标志性文案开头
5. **example_copy 必须体现该平台特有的语言风格**，小红书要真实分享感，抖音要口语化节奏感
6. 视觉指导要配合现有品牌视觉系统，不是重新设计
7. 调性要可被内容创作者理解和执行，不要过于抽象
