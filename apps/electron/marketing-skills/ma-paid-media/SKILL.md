# 付费媒体投放策略

## 这个 Skill 做什么

规划系统性的付费媒体投放策略：
- **阶段规划**：预热期/爆发期/持续期的投放目标和预算
- **渠道策略**：各平台的投放类型、定向策略和预期 CPM
- **素材策略**：各阶段使用的素材类型和创意方向
- **预算分配**：按平台和阶段的预算拆解
- **KPI 设定**：各阶段的核心指标目标

## 何时使用

**合适的场景：**
- 付费广告预算规划
- 新品上市的效果广告投放
- 大促节点的流量获取策略
- 品牌曝光与效果转化的组合策略
- 季度/年度投放复盘和优化

**不合适的场景：**
- 纯 organic 的内容策略（不需要付费投放）
- 没有预算信息时（无法规划）
- KOL 合作规划（用 ma-kol-pyramid）

## 工作流

### Step 1 · 目标与预算确认

确认以下信息：
| 信息项 | 说明 |
|--------|------|
| 总预算 | 付费投放总预算 |
| 投放目标 | 品牌曝光/种草/转化/拉新 |
| 目标平台 | 计划投放的平台 |
| 时间周期 | 投放周期和关键节点 |
| TA 画像 | 影响定向策略 |
| 素材能力 | 视频/图文/互动素材的制作能力 |

### Step 2 · 阶段规划

设计预热期、爆发期、持续期的投放策略。

### Step 3 · 预算与 KPI 拆解

按平台和阶段分配预算，设定可衡量的 KPI。

## 规则

1. **预算 < 10万时，集中1-2个平台**，放弃开屏等高单价资源，聚焦信息流和搜索
2. **每个 placement 必须有明确的 targeting 策略**，不是"精准定向"这类空话
3. **expected_cpm 基于行业基准给出区间**，不是精确数字，标注数据来源或基准
4. **素材和投放渠道必须匹配**：视频素材优先投视频平台，图文素材投信息流
5. **B2B 场景增加 LinkedIn Ads、知乎知+、百度 SEM** 等 B2B 渠道
6. 阶段划分要符合用户决策链路：认知→兴趣→转化→复购
7. 预算分配要符合漏斗模型：上层漏斗（曝光）占比通常高于下层（转化）
