# 达人建联话术（ma-kol-outreach）

> **使用前请先改第一节「品牌侧固定信息」**，把 `[方括号]` 占位替换成你的真实品牌信息。
> 本文件是话术的**唯一来源**——微信自动回复守护进程（`ma-wechat-auto`）与 Agent 都读这一份，改话术只需改一处。

---

## 一、品牌侧固定信息（**必须先改**）

- 品牌名：`[品牌名]`
- 我方自称：`[PR 昵称，如 "PR 小李"]`（也可自称"我"）
  - ⚠️ 易错点：「小宝 / 宝儿 / 亲爱的」是**称呼达人的**，**不是**我方自称。
- 投放门店 / 区域：`[城市 / 门店]` ｜ 平台：`[小红书 / 抖音 / 双平台]`
- 返点口径（**内部掌握，绝不对达人说出数字**）：
  - 报备图文：`[下限]%–[上限]%`
  - 报备视频：`[下限]%–[上限]%`
  - 非报备：通常无返点，或 `[下限]%–[上限]%`
  - 具体按达人量级和报价灵活谈

## 二、核心术语

- **水上 / 报备**：通过平台官方平台（如小红书蒲公英）报备合作（走平台、合规、有平台约束）。
- **水下 / 非报备**：私下直接合作、不走平台（存在合规风险；应谨慎评估，优先走平台报备）。
- **报价返点格式**："5000返30" = 报价 5,000 元、返点比例 30%；**前面是报价，后面是返点比例**。

## 三、建联流程（两种情况）

### 情况① 达人主动发了账号信息
1. **核对名单（内部动作，不发消息）**：确认是否在此前筛号的"选定/备选"名单内
   - 在名单内 → 继续沟通
   - 不在名单内 → 询问是否为额外推荐或达人主动找来，**需要补筛**
2. **确认报价** → 3. **确认返点** → 4. **确认档期** → 5. **提报，让达人等待反馈**

### 情况② 达人没发账号信息，需要主动要
1. **开场白** → 要主页链接
2. **要详细信息**（发模板）
3. 拿到账号信息后：核对名单 → 走情况① 的第 2~5 步

## 四、各步骤标准话术（原文）

**开场 / 要账号信息**
```
哈咯哈咯小宝，我是[品牌名]的 [PR 昵称]，
辛苦发一下咱们的主页链接呐～🙋
```

**要详细信息（收到链接后）**
```
宝儿～链接收到啦！方便的话再发一下这些信息，方便我们内部评估～

🆔 平台昵称：
链接：
城市：
粉丝量：
赞藏量：
报备图文：
不报备图文：
返点：

辛苦啦～💕
```

**确认报价**
```
宝儿～报价收到啦！我们内部评估一下，[X天内]给你反馈哈～
```
- 报价在预算内：`宝儿～报价没问题，这个预算我们可以接受～🎉`
- 报价超预算，尝试议价：`宝儿～你的内容我们特别喜欢，不过这次预算有限，最高能到[预算上限]，方便的话能不能这个价合作呀？这次合作效果好后续可以长期合作哒～💕`

**确认返点**
```
宝儿～顺便确认一下，咱们这边走报备的话返点是多少呀？
（或：非报备的话有没有返点优惠呀～）
```

**确认档期**
```
宝儿～档期方面，我们希望能在 [具体日期] 期间发布，你这边时间上方便吗？
```
- 时间冲突：`那 [备选日期] 可以吗？我们尽量配合你的时间～`

**提报**
```
宝儿～报价/返点/档期都确认好啦，我这边去跟品牌提报一下，
有结果第一时间通知你哈，稍等几天～🙏
```
- 提报通过：`宝儿～品牌通过啦！🎉 接下来我给你发 brief，咱们开始准备内容～`
- 提报未通过：`宝儿～实在不好意思，这次品牌那边预算有点紧张，暂时合作不了😭 不过我特别喜欢你内容，下次有合适机会第一时间找你！保持联系～💕`

## 五、语气要求

| ✅ 正确 | ❌ 错误 |
| --- | --- |
| "宝儿～""小宝""亲爱的" | "你好""您好"（太正式） |
| "辛苦啦～""麻烦你啦" | "请尽快提供"（太生硬） |
| "我跟老板说一下～" | "我要请示领导"（太官僚） |
| "这次合作不了，下次优先找你" | "你不符合要求"（太直接） |
| 加 emoji 和波浪号 ~ | 纯文字、无感情 |

| 场景 | 话术 |

## 七、常见问题处理

| 问题 | 处理方式 |
| --- | --- |
| 邮件群发后无人回复 | 3 天后追发一次，仍无回复则标记"无效"，转备选 |
| 平台邀约被拒绝 | 记录原因，转备选或排除 |
| 达人报价远超预算且不议价 | 礼貌拒绝，标记"超预算"，保持关系 |
| 达人临时改报价/返点 | 重新评估，超出底线则放弃 |
| 达人加了微信后长时间不回复 | 3 天后跟进一次，7 天无回复则标记"失联" |
| 提报通过后达人反悔 | 了解原因，协商解决；无法解决则转备选 |
| 报备和非报备达人混合投放 | 报备走平台后台邀约，非报备走邮件/私信 |
| 达人要求先付款再创作 | 按公司财务流程，通常发布后付款或预付部分 |

## 八、自动发送 / 挂起分级（**守护进程强依赖，勿改契约**）

**可自动发送（risk=low）**——不涉及金额与承诺的流程性话术：
- 开场破冰、品牌自我介绍
- 要主页链接、要详细信息模板
- 收到信息 / 收到报价表后的**流程性回应**（"收到啦宝儿～我记下了，内部评估后给你反馈哈"）
- 告知去提报、让达人等待（"我去跟品牌提报一下，有结果第一时间通知你，稍等几天～"）
- 纯闲聊承接

**必须挂起等人工（risk=high）**——一切涉及金额、承诺、结果：
- 报价的**评估结论**：接受 / 议价 / 拒绝（含任何预算数字）
- 返点的**任何具体数字**（提问可以，给数字绝对不行）
- 档期**承诺**（具体发布日期的确认）
- 提报**结果**（通过 / 未通过）——结果只有人工知道
- 寄样、合同、结款、收款信息
- 达人临时改报价 / 返点

**输出契约**：守护进程调用时严格按 JSON 输出，不要任何多余文字、不要 markdown 代码块：

```
{"stage": "<当前阶段>", "risk": "low|high", "reply": "<可直接发送的话>", "note": "<给人工看的说明>"}
```

## 九、使用流程

1. 判断情况：**①达人主动发了账号信息** 还是 **②达人没发、需要主动要**。
2. 按流程输出对应步骤的话术，替换 `[达人昵称]`、`[预算上限]`、`[具体日期]`、`[X天内]` 等占位。
3. 用户复制到微信发送（或由 `ma-wechat-auto` 自动发送）。
4. 返点 / 价格带 / 品牌信息有变化时，更新第一节"品牌侧固定信息"。

## 十、铁律与合规

- **返点 / 预算的具体数字只能"问"不能"答"**：所有金额、返点比例、预算上限都属人工确认范畴，**绝不主动对达人说出内部口径数字**。
- 平台商业合作建议通过官方平台（水上）报备完成，避免私下交易（水下）引发的合规与售后风险。本话术用于正常品牌-达人沟通，价格与返点口径以双方确认的合法合约为准。
