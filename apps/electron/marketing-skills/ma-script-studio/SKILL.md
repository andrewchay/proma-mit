# 脚本工坊

## 这个 Skill 做什么

为达人内容创作提供专业的脚本执行方案，覆盖三种核心脚本类型：
- **故事脚本（story）**：完整的故事弧线、场景分解、对话设计和视听注意点
- **分镜脚本（storyboard）**：逐镜头的分镜表、灯光/道具/场地建议
- **视频拍摄指导（video_guide）**：拍摄设备/灯光/收音方案、后期节奏/转场/BGM建议

同时提供平台适配和品牌植入检查，确保脚本可落地执行。

脚本层内建两套心理学框架：
- **说服设计（Cialdini 六原则）**：互惠 / 承诺一致 / 社会认同 / 权威 / 喜好 / 稀缺——脚本要显式设计至少两条说服要素并标注位置
- **传播设计（STEPPS 落地）**：开头钩子用"好奇缺口 + 高唤醒情绪"，CTA 用社会认同 + 稀缺，产品信息包进故事（叙事运输降低说服防御）

## 何时使用

**合适的场景：**
- 达人内容创作的脚本撰写阶段
- 品牌合作内容的拍摄前准备
- 需要分镜表指导拍摄执行
- 视频拍摄团队需要设备/灯光/收音方案
- 多平台内容需要调整脚本格式和时长

**不合适的场景：**
- 创意概念和 Big Idea 发想阶段（用 ma-creative-concept）
- 纯平面图文内容创作
- 没有品牌/产品/平台信息时

## 工作流

### Step 1 · 输入确认

确认以下信息是否充足：
| 信息项 | 说明 |
|--------|------|
| 品牌 | 品牌名称和核心信息 |
| 产品 | 产品卖点和关键信息 |
| 平台 | 目标发布平台（小红书/抖音/B站等） |
| 脚本类型 | story / storyboard / video_guide |
| 时长 | 目标视频时长 |
| 风格 | 内容风格调性 |

### Step 2 · 脚本生成

根据脚本类型生成对应内容：

- **story 类型**：构建故事弧线（设定-冲突-解决-CTA），逐场景分解，撰写完整对话，标注视听注意点
- **storyboard 类型**：逐镜头设计分镜表（镜头/角度/运动/时长/画面/台词），提供灯光/道具/场地建议
- **video_guide 类型**：制定拍摄设备/灯光/收音方案，规划后期节奏/转场/BGM，提供平台-specific 技巧

生成时同步完成**说服设计**：为脚本标注至少两条 Cialdini 要素的落点——如互惠（先给干货/福利再谈产品）、权威（真实专家/实验/检测背书，禁止虚构）、喜好（相似性与真诚赞美，不油腻）、社会认同（"评论区都在说"式从众）、承诺一致（让用户先做小承诺：评论肤质/扣 1）、稀缺（限时/限量/专属，须真实）。

### Step 3 · 平台适配与品牌植入检查

根据平台规范调整脚本格式和时长，检查品牌信息是否自然融入，不生硬。

## 规则

1. **脚本时长必须严格匹配平台规范**：小红书 60s 内 / 抖音 15-60s / B站可长，超出时长必须标注并给出压缩建议
2. **品牌植入要自然**，每 15-20s 至少有一个品牌露出点，避免生硬口播和突兀的产品展示
3. **开头 3 秒必须有钩子（hook）**，否则完播率会低，hook 可以是悬念/冲突/反常识/利益承诺
4. **对话要口语化**，避免书面语和广告腔，使用目标受众的真实语言习惯
5. **分镜要标注镜头运动方式**：固定 / 推 / 拉 / 摇 / 跟，每个镜头运动要有明确的叙事目的
6. **BGM 建议要匹配情绪曲线**，不是简单推荐热门歌曲，而是按场景标注情绪需求和节奏要求
7. **如果品牌信息不足**，标注需要补充的信息项，不虚构品牌卖点
8. **开头 3 秒钩子 = 好奇缺口 + 高唤醒情绪**：好奇缺口制造"想知道答案"的张力（意外/反常识），情绪选敬畏/兴奋/幽默/愤怒/焦虑等高唤醒情绪，避免低唤醒的"满足感开场"；hook 同时要含社交货币潜质（转出去显得会挑/懂行）
9. **CTA 必须踩至少一条说服原则**：承诺一致（评论肤质/扣 1/许愿）、社会认同（"已囤的姐妹都说"）、稀缺（真实限时限量）三选一以上；纯"点关注"式 CTA 视为未完成说服设计
10. **权威要素必须真实**：专家/机构/实验数据须为 brief 提供的真实背书，脚本不得虚构权威（虚构归合规问题）；稀缺同理，编造的"最后 3 件"不写进脚本
11. **产品信息包进故事**：优先用叙事运输（剧情/亲历故事）承载卖点，降低观众的说服防御；硬口播仅在合规必需时使用并标注
