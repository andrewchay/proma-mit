## 关键路径

1. P0 数据 Schema、输入校验和 package smoke 收口。
2. P1 小红书交接与报表导入可独立上线。
3. P2 用自有公众号测试账号验证官方 API。
4. P3 并行申请微信开放平台资质；获批后完成多租户授权。
5. P4 仅在获得书面 scope、白名单或合法数据供应商后启用商业能力。
