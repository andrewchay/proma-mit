# 官方 Proma 4.27 之后 Bug Fix 汇总（v0.9.10 → v0.16.8）

> 生成时间：2026-08-03，数据来源：官方 GitHub Releases

## v0.16.8 (2026-08-03)
- **Pi 上下文溢出恢复** — 修复 Pi 运行时上下文溢出后无法正常恢复的问题，溢出后可自动恢复继续对话。
- **64K 输出上限只对真正的 Claude 模型生效** — 修复因模型 ID 包含 `claude` 子串（如自定义 fork、`gateway/claude-proxy` 代理别名）而被误注入 `CLAUDE_CODE_MAX_OUTPUT_TOKENS=64000` 的问题；现在仅按真实 Claude 家族名判断，覆盖 `claude-sonnet-4-6` 与 `claude-3-5-sonnet-20241022` 两种命名形态。
- **Scratch Pad 底部编辑缓冲保留** — 修复 Scratch Pad 底部编辑缓冲在特定交互下被清空的问题，编辑内容不再意外丢失。
- **浅色主题选中文字前景色修复** — 修复浅色主题下选中文本前景色异常，文字选中后依然清晰可读。
- **Vision Relay 运行时打包修复** — 修复 Vision Relay 依赖的 `sharp` 运行时打包缺失，图片处理在生产包中可用。
- **OAuth 授权请求统一走应用代理** — 渠道 OAuth 授权请求改为经应用代理发起，授权流程在代理环境下更稳定。
- **macOS 26 前禁用灵动岛** — 在 macOS 26 兼容性就绪前暂时禁用 Agent 灵动岛，避免新系统上的异常表现。

## v0.16.7 (2026-08-01)
- **Windows 剪贴板复制统一走主进程** — 修复 Windows 上代码块、Mermaid 图、消息等场景复制失败的问题：新增统一复制工具，优先经 Electron 主进程写入系统剪贴板，规避 renderer 剪贴板权限限制。
- **Windows 规划窗口操作修复** — 修复 Windows 独立规划窗口标题栏拖拽区域与窗口控制按钮重叠导致的交互异常，窗口拖拽与关闭操作恢复正常。
- **灵动岛已完成状态同步** — 修复"完成但未查看"的标记在会话打开后未正确清除的问题；已读确认只作用于活跃会话，避免误清状态。

## v0.16.5 (2026-07-31)
- **提及菜单 Esc 行为修复** — 按 `Esc` 关闭后不再被同一触发片段再次弹出；修复 `@` 文件弹窗并发竞态导致的「无匹配文件」，并对 `/`、`#`、`&`、`~`、`～` 等全部提及触发符统一加固。
- **OpenCode Go 标题生成加固** — 修复推理模型（`grok-4.5` / `kimi-k3` / `deepseek-v4` 等）会话长期停在默认标题的问题：标题请求增加 30 秒超时、兼容内容块数组响应、所有失败路径（解密失败、请求异常、空标题）都会回退到本地标题生成。
- **Codex OAuth 标题并行生成** — OAuth 渠道的会话标题改为并行生成，避免逐个等待拖慢体验。
- **经典视图 + 深色主题设置面板导航变白** — 修复经典视图下设置面板左侧导航在深色主题中被浅色硬编码覆盖的问题。
- **灵动岛空闲 Dashboard 保持可见** — 修复空闲状态下 Dashboard 偶发消失的问题，并保留全天日程事件的展示。

## v0.16.3 (2026-07-30)

## v0.16.1 (2026-07-30)
- **长对话更稳定** — Pi 会更早整理过长上下文，并在整理后继续执行任务、保留进度显示。
- **网络异常自动恢复** — Pi 遇到网络抖动或上游流式响应异常时会自动重试，减少回答中断或卡住的情况。
- **运行中切换模型** — Agent 运行时可以预先切换模型，当前轮结束后会自动按新模型执行下一轮。
- **命令与引用输入更可靠** — 连续调用 `/` 命令时，文件路径和旧草稿中的引用不会再被误识别为命令。
- **协作会话状态同步** — 委派给子 Agent 的会话在创建、运行和结束时会正确更新界面状态，并沿用当前模型。
- **随时停止 Agent** — Agent 运行中即使已输入下一条消息，停止按钮仍会保留，可随时中止当前任务。
- **内核与推理设置平稳切换** — 内核和推理强度的修改会在当前任务结束后生效，避免中途打断。
- **自动处理明确计划项** — 自动模式下，Agent 可以直接删除已明确指定的待办和日程。
- **待办数量更准确** — 待办和分组中的数量不再计入已完成的项目。
- **侧栏固定会话不再受限** — 可以在侧栏固定任意数量的会话。
- **Excel 预览更多数据** — 每个 Excel 工作表的预览最多可显示 200 行数据。
- **渠道与模型兼容性改进** — 修复飞书新机器人会话镜像，以及不同渠道下 Claude 模型识别的问题。
- **其他体验修复** — 修复 Codex 会话标题偶发冲突、PDF Skill 识别和引用内容后焦点跳转等问题。
