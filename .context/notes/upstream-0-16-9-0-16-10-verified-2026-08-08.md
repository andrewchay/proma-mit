## 四、真正值得借鉴的（按优先级）

1. **非 Git 项目的变更面板**（高，明确差异）
   - Gravitas 改动面板完全依赖 git diff，**非 git 项目打开会话时改动不可见**。Proma 用 `workspace-watcher` + `session-file-changes.ts` 让 Agent 会话产物（即便无 git）也能按轮次展示/预览/定位。
   - **建议落地**：参照 Proma `useGlobalAgentListeners` + `DiffChangesList` 改造，为本地非 git 项目提供会话产物变更视图。

2. **Mention 误触发抑制**（中，明确 bug）
   - 抄 `shouldAllowMentionTrigger({paragraphText, triggerOffset, trigger, isCodeContext})` — 判断光标前的段落文本是否 URL/邮箱/路径等，避免粘贴时误弹 `@`/`/`/`#`/`&` 菜单。
   - **建议落地**：移植 `mention-utils.ts` 逻辑到现有 mention-suggestions。

3. **EventKit 双向同步**（中，功能增强）
   - 现有桥接是单向读取；Proma 已做双向 + 冲突解析。Gravitas 凭其日程管家优势（月视图+冲突检测）可更进一步补「写回系统日历」。
   - **建议评估**：结合本项目日程管家路线，判断双向写回是否为 P0。

4. **Splash / FAQ**（低，体验增强）：可选项，锦上添花。

## 五、结论

v0.16.9/v0.16.10 相比 0.16.7/0.16.8 更偏交互与平台打磨，且 Gravitas 已有的多为"单边"能力。真正值得动手的差距收敛到两点：
- **① 非 Git 项目会话产物可见**（改动面板补 watcher 兜底）
- **② Mention 误触发抑制**（小 bug，低风险高回报）

EventKit 双向同步作为日程管家的中期演进；Splash/FAQ 列为可选项。
