# Gravitas v0.11.18

> 对比基准：v0.11.17

本次版本让 **SubAgent 委派并行执行**：同一轮内多个子代理可并发运行，显著缩短多子任务场景的等待时间。

## SubAgent 委派并行执行

- **同一轮多个子代理并发运行**：当 Agent 委派多个独立子任务时，按要求并行执行，而非串行排队
- 配合串行工具保持顺序，兼顾并行效率与执行依赖正确性

## 架构说明

- agent runtime：SubAgent / 普通工具 `Promise.all` 并发，串行工具保持顺序（provider-agnostic-adapter 重构）
- 常见场景：并行探索、多子系统同步调研等

## 开发与文档

- 版本更新 — `@gravitas/electron` 从 `0.11.17` 升级到 `0.11.18`
- 定位根因：provider-agnostic-agent-adapter 工具串行执行
