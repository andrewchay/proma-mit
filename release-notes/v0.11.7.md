# Proma v0.11.7

> 对比基准：v0.11.6

本次版本新增 **Token 消耗统计后台**，并改进 macOS 构建脚本。

## Token 消耗统计后台

- 新增 Token 用量统计能力：按会话/模型/渠道维度统计 Token 消耗，便于掌握成本与用量分布
- 接入设置 Tab，可在后台查看 Token 消耗情况

## 构建脚本改进

- `build-mac-app.sh` 支持从**项目根目录**和 `scripts/` 目录两种位置运行，构建命令更灵活

## 架构说明

- 主进程：新增 Token 用量统计采集与查询逻辑
- 渲染层：设置页新增 Token 消耗统计面板

## 开发与文档

- 版本更新 — `@proma/electron` 从 `0.11.6` 升级到 `0.11.7`
- 更新 README / docs/code-index.md
