# Gravitas v0.11.19

> 对比基准：v0.11.18

本次版本引入 **Agent 模式会话级发送排队**：流式期间可连续发送消息，排队消息可撤回 / 立即执行。

## Agent 模式会话级发送排队

- **流式期间连续发送**：Agent 还在输出时即可继续输入下一条，不再被阻塞
- **排队可撤回 / 立即执行**：排队中的消息可撤回，或指定立即执行
- **会话级 FIFO 队列**：入口排队 + `pumpNext` 逐条执行，配合 promote / cancel / status 管理
- **状态广播**：`queue_state` 事件实时同步前端排队状态

## 架构说明

- agent runtime：orchestrator 会话级 FIFO 队列 + 入口排队 + pumpNext + promote/cancel/status
- IPC / preload + agent-service 薄包装 + queue_state 广播
- 渲染层：排队贴片 + AgentView handleSend 入队 + 全局订阅校正

## 开发与文档
