# Gravitas v0.11.17

> 对比基准：v0.11.16

本次版本是 **品牌更名里程碑**：Proma MIT 正式更名为 **Gravitas**（appId = `com.gravitas.app`），许可证调整为 **BSL 1.1**，并伴随一轮品牌物料、UI 与教程大更新。

> 从本版本起，产品正式以 **Gravitas** 品牌对外，发布说明与安装包均改用 `Gravitas-*` 命名。原 Proma MIT 阶段版本记录仍沿用 Proma 命名（见下方历史）。

## 品牌全面更名 Proma → Gravitas

- **全线更名**：应用名 / appId / 品牌文案 / 欢迎页全量切换至 **Gravitas**
- **许可证调整**：开源协议由 `Apache-2.0 OR MIT` 改为 **BSL 1.1**，并明确 Gravitas 为 Proma 的衍生作品、Additional Use Grant 生产规模阈值定为 10 最终用户
- **品牌素材**：集成 Gravitas 10 变体 Logo 系列并更换主应用图标；品牌素材页升级，清理 Proma 官方渠道推广文案

## 图标与 Dock 优化

- 集成**水墨 / 油画风艺术变体图标**（青花瓷、印象派、青绿山水等）
- 多轮打磨 Dock 图标比例（76% → 60% → 50% 居中缩进）与圆角透明（四角 alpha=0）
- 修复 Dock 图标圆角 / 方形问题：default 不 setIcon、加回 `app.dock.show()`、移除窗口 icon 覆盖

## 教程与欢迎文大幅升级

- 重写教程头部与元数据，适配 Gravitas 品牌与衍生声明
- 教程新增 **Computer Use（电脑控制）**、**项目管理、日历同步、飞书通讯录绑定**章节
- 清理残余 Proma 品牌文案（i18n 全面切至 Gravitas）

## 飞书 / 日历 / 交互修复

- 飞书：扫码创建机器人（registerApp）、通讯录 40004 容错与响应解析优化、批量权限清单补全、改用 v3 分页拉取全量用户、移除无效权限、诊断提示细分可见范围 vs 权限问题
- 日历：补 macOS 日历权限声明，修复日程同步授权
- 项目：飞书/钉钉 Todo 配置入口与 Bot 保存联动、会话星标移到标题行可点击、项目下默认展示会话数 3 → 5
- 灵动岛：点击默认关闭、确认后无待处理即收起、无需审批时不触发弹窗
- Server：真实 Provider 矩阵补 `deepseek-openai`，消除恒失败红灯；修复工具调用悬空 span 的数据完整性；修复 AI 员工执行与 Goal 配额 / 权限 / 依赖多处逻辑漏洞

## 架构说明

- 全仓：品牌标识 / 许可证 / 应用元数据统一更名
- electron：Dock 图标与品牌物料走 icns / png 圆角透明方案
- 教程查看器：承载 Computer Use 等新增章节
