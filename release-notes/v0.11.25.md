# Gravitas v0.11.25

> 对比基准：v0.11.24

本次版本是 **AgentIC OS（团队 Agent 协作操作系统）大迭代**：PH1 团队基建 + PH2 平台开放一次落地，同时补齐若干 Agent / 飞书稳定性修复。方案见 `.context/plan/gravitas-agentic-os-phased-plan.md`。

> PH1 & PH2 主链路已全部收尾，含本地集成测试套件（服务层直接验证主链路）与 `[Diag]` 诊断日志。

## PH1：团队基建

- **成员同步**：飞书 / 钉钉成员同步与双向 mapping（真人 ↔ AI 员工 ↔ Bot）
- **统一成员视图**：真人 / AI 员工 / Bot 聚合，一侧查看全部成员
- **负责人选择器统一**：真人 / AI 员工同处可选可指派
- **统一事件事实源**：事件流带成员归属（PH1-C 最小版）
- **审计收口**：审计记录带成员归属（PH1-D 最小口径）

## PH2-A：团队协作能力

- 团队 Skills 目录视图（轻量）
- 工作区文件共享事件流（数据层 + UI 面板补全）
- Todo 事件流化、Agent 解压缩工具 InspectTodo
- 团队级 Profile

## PH2-B：Run Center

- Run Center 增强——按成员归属过滤与展示
- Run Center 导出运行记录

## PH2-C：团队收件箱与可回放

- 团队收件箱 **Mailbox**（首版）＋ 扩源（待办 / 看板并入收件箱）
- Proactive 动作可回放、自动服务器 / 费用 Audit
- 灵动岛状态无变化跳过（PH2-C 收尾）

## PH2-D：上下文 / 成本 / 资产 / 安全

- 本地 **Context Hub / Work Graph**、Token 成本记账收敛、成功输出转可复用资产提案
- 凭据统一治理 + 审批门收敛

## PH2-E：Bridge 即远程入口

- Bridge 即远程入口——`/workflow` 与 `/proactive` 远程触发

## PH2-F：成员互调与平台开放（收尾）

- 成员间 Agent 互调协议、插件 / SDK 开放 + 多租户精细化

## 稳定性修复

- Agent：轻量文件日志落盘 + 会话开始/完成/失败/断流重试记录；协作子会话继承父会话 modelId、Pi runtime 子会话 modelId fallback、缺模型兜底默认模型、补传 channelId、`resolveCollaborationWorkspaceId` try/catch 防御
- 飞书：Task v2 创建任务改用 `members(role=assignee)` 设置负责人，修复飞书 Todo 不显示
- 构建：electron-builder 打包前递归清理 `out/` 下 `.DS_Store`，根治 ENOTEMPTY

## 架构说明

- 数据层 / 服务层：成员、事件、审计、Run、Mailbox、Context Hub、成本、SOP 等模型（含兼容旧库迁移）
- 渲染层：团队成员、Skill、文件流、Mailbox、Run Center、审计等相关面板
- agent runtime：成员互调、插件 / SDK 开放、协作子会话稳定性加固
