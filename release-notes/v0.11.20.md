# Gravitas v0.11.20

> 对比基准：v0.11.19

本次版本深入加固**飞书通讯录负责人搜索**，修复「指定责任人拉不到人」的根因链路。

## 飞书通讯录搜索加固

- **部门枚举加深**：部门数据结构完善，支持更深层级的部门成员抓取
- **双部门 ID 类型并集**：`find_by_department` 同时兼容枚举 ID 与 open_department_id，覆盖权限范围差异
- 修正 `/departments/children` 字段解析（`data.items` 而非 `data.children`）

## 平台构建脚本品牌一致

- `build-mac-app.sh` 注释同步 Proma MIT → Gravitas（保持品牌一致）

## 架构说明

- electron：`contact-search-service` 通讯录负责人搜索加固

## 开发与文档

- 版本更新 — `@gravitas/electron` 从 `0.11.19` 升级到 `0.11.20`
- 根因分析见 `.context/notes/feishu-contact-search-deepdive.md`
