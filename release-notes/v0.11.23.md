# Gravitas v0.11.23

> 对比基准：v0.11.22

本次版本新增**手动「并行协作子任务」入口**，可靠触发协作子会话树。

## 手动「并行协作子任务」入口

- 用户可**手动拆分**主任务为多个并行协作子任务，显式触发协作子会话树执行
- 为需要自行编排并行拆分的场景提供稳定入口

## 架构说明

- agent runtime：手动并行协作子任务入口（协作子会话树触发）
- 渲染层：对应操作入口

## 开发与文档

- 版本更新 — `@gravitas/electron` 从 `0.11.22` 升级到 `0.11.23`
