# Proma v0.11.11

> 对比基准：v0.11.10

本次版本完成 Goal **P1：引入运行证据与配额机制**。

## Goal P1：运行证据与配额

- 引入**运行证据（Evidence）**：Agent 运行过程沉淀可留痕、可回溯的运行证据
- 引入**配额机制（Quota）**：为 Goal 执行设定 / 消耗额度，避免运行失控
- 结合 P0 的状态层，为后续决策层与目标闭环提供依据

## 架构说明

- server：Goal 配额与证据模型
- electron：Goal 状态层接入配额与证据语义

## 开发与文档

- 版本更新 — `@proma/electron` 从 `0.11.10` 升级到 `0.11.11`
