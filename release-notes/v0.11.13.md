# Proma v0.11.13

> 对比基准：v0.11.12

本次版本**打通 Goal 闭环**：会话绑定、决策 UI、Agent 工具与配额阻断全链路落地。

## Goal 闭环打通

- **会话绑定**：Goal 与具体会话建立绑定关系，运行语境可回溯
- **决策 UI**：决策点提供可视化界面，可人工确认 / 干预
- **Agent 工具**：Agent 侧提供 Goal 相关工具能力
- **配额阻断**：运行超出配额时自动阻断，防止失控

## 架构说明

- server：Goal 闭环服务（会话绑定 / 决策 / 配额阻断）
- electron：决策 UI 与 Goal 绑定逻辑

## 开发与文档

- 版本更新 — `@proma/electron` 从 `0.11.12` 升级到 `0.11.13`
