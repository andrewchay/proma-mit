# Proma v0.11.3

> 对比基准：v0.11.2

本次版本落地「项目管理 AI 员工（Agent Employee）」P0 核心闭环：在项目团队中定义 AI 员工，任务指派后由 Agent 无人值守执行并回写结果。方案见 `.context/notes/ai-employees-design.md`。

## AI 员工（P0）

- **员工档案**：项目管理 → 团队 Tab，可新建/编辑/启停 AI 员工（名称、角色、能力描述、Runtime、渠道、模型、自定义 system prompt）
- **指派与执行**：新建任务时可选择 AI 员工（🤖），任务创建/确认后自动走 AgentTodoProvider，由 headless Agent 会话执行（默认 safe 权限）
- **结果回写**：执行完成自动回写任务状态（completed）与完成说明，失败回退 paused 可重试；执行记录写入 `agent_executions` 并生成项目活动流
- **心跳保活（60s）**：每分钟扫描运行中执行，`isAgentSessionActive` 探测会话存活；失联标记 `stale` 并回退任务；超过默认 60min 超时自动中止
- **执行记录**：团队 Tab 展示每员工执行概览（状态/摘要/时间），任务行显示 AI 执行状态徽标

## 架构说明

- 数据层：`project-sqlite-store` 新增 `agent_employees` / `agent_executions` 两表（含员工统计、执行心跳/超时字段）
- 服务层：新增 `agent-employee-service.ts`（员工 CRUD + AgentTodoProvider + headless 执行编排 + 60s 心跳扫描）；`project-auto-sync` 按 assignee 分流（AI 员工 → agent，真人 → 飞书/钉钉）
- 执行器：复用 `agent-headless-runner-registry` / `agent-service.isAgentSessionActive` / `stopRegisteredAgent`
- IPC/Preload：shared 新增 `AGENT_EMPLOYEE_IPC_CHANNELS` 与类型；`electronAPI.paa.agentEmployees` 暴露 7 个 API
- UI：`AgentTeamPanel.tsx`（团队管理）+ ProjectView 团队 Tab / 新建任务 AI 员工选择 / 任务行执行状态

## 权限与安全（P0 基线）

- 执行默认 `safe` 权限；by-task 权限申请/审批为 P1 计划
- 共享项目工作区（员工子目录隔离与并发上限为 P1 计划）
- 心跳保活 + 超时中止 + stale 回退，避免任务永久悬挂
- 全部执行写入 `agent_executions` + 项目活动流，可审计

## 升级建议

- 在「项目管理 → 团队」创建 AI 员工后，新建任务选择 AI 员工即可体验完整闭环
- 需要至少一个已启用渠道（模型配置）；AI 员工默认使用当前工作区执行
