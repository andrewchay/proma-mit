# Gravitas v0.11.21

> 对比基准：v0.11.20

本次版本修复 **SubAgent 子代理 baseUrl 未按 runtime 转换导致 404** 的问题。

## SubAgent baseUrl runtime 转换修复

- 子代理 baseUrl 未按当前 runtime（Claude / Pi / AI SDK 等）正确转换，导致请求打到错误地址返回 404
- 统一 baseUrl 的 runtime 转换逻辑，确保多 runtime 下子代理正常发起请求

## 架构说明

- agent runtime：SubAgent 子代理 baseUrl 按 runtime 转换修复

## 开发与文档

- 版本更新 — `@gravitas/electron` 从 `0.11.20` 升级到 `0.11.21`
