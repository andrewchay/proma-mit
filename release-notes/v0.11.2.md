# Proma v0.11.2

> 对比基准：v0.11.1

本次版本为模块合并（Module Consolidation）：收敛设置面板与工作模块的入口数量，并建立模块注册表框架，防止后续模块继续膨胀。设计提案见 `.context/notes/module-consolidation-proposal.md`。

## 工作模块：4 → 3（删除"任务"占位）

- **移除「任务」占位模块**：任务概念归属明确（项目管理 → 任务/看板/我的工作；日程管家 → 任务看板），不再单设入口。删除 `ModulePlaceholderView.tsx` 与 ActiveView 中的 `tasks`
- **「自动任务」→「自动化」聚合视图**：新增 `AutomationModuleView`（运行中 / 定时任务 / 运行记录 三个子视图），把原分散在工作模块（自动任务运行中心）与设置面板（定时任务、运行记录）的三处"自动化"能力收敛为一个主入口

## 设置面板：21 Tab → 4 组分组导航

- 左侧导航改为分组结构：**基础配置** / **模型与智能体** / **连接与同步** / **系统与隐私**
- 低频组（系统与隐私）默认折叠，组标题可点击展开/收起
- 设置内移除「定时任务」「运行记录」两个 Tab（已并入工作模块「自动化」）；「设备控制」保留

## 模块注册表框架（4.3）

- 新增 `atoms/work-module-registry.ts`：`WORK_MODULE_REGISTRY`（label/icon/core/description）+ `WORK_MODULE_VIEWS`（id → 组件）
- 左侧边栏工作模块列表与 MainArea 渲染改为注册表驱动，新增模块只需注册一处
- 当前 3 个核心模块：日程管家 / 项目管理 / 自动化；注册表已支持 `core` / `group` 字段，未来可承载扩展模块（PAA 剩余模块按分组接入）

## 架构说明

- 渲染层：删除 `AutomationCenterView.tsx`（拆为 `AutomationRunningPanel.tsx` 无顶栏面板，供 AutomationModuleView 复用）；`SettingsPanel.tsx` 重构分组导航
- `ActiveView` 类型：`'tasks'` 移除
- 设置 `SettingsTab` 类型：`'scheduler'` / `'run-center'` 移除

## 升级建议

- 定时任务与运行记录入口已从「设置」移入「工作模块 → 自动化」，请从侧边栏工作模块进入
- 若此前在设置里创建过定时任务，数据不受影响（仍在本地存储）
