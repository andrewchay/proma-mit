# Gravitas v0.11.24

> 对比基准：v0.11.23

本次版本新增**「并行协作子任务」一键自动拆分**：只填主任务，模型自动拆分成子任务并行执行。

## 「并行协作子任务」一键自动拆分

- **只填主任务**：无需手动拆分，指定主任务即可
- **模型自动拆分**：Agent 理解主任务后自动拆分为适合并行的子任务
- **自动并行执行**：拆分后的子任务并行运行，最后合并结果，缩短整体耗时

## 架构说明

- agent runtime：一键自动拆分子任务 + 并行协作执行

## 开发与文档

- 版本更新 — `@gravitas/electron` 从 `0.11.23` 升级到 `0.11.24`
- 使用场景：复杂长任务交由 Agent 自动分解并行，显著提速
