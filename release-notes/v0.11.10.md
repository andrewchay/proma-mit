# Proma v0.11.10

> 对比基准：v0.11.9

本次版本在 server 侧完成 **Goal 状态层 P0**，并推进运行档案到 **P-IV（Signals / 自查档案 / 评估数据集 / Web UI）**。整体借鉴 LoopX 控制平面思想。

## Goal（目标）P0：引入 Goal 状态层

- 引入 Goal 状态层（借鉴 LoopX 控制平面），为后续目标闭环、配额与决策层作出顶层设计

## Server：运行档案增强（P-I → P-IV）

- **P-I 补齐**：trace 闭环 + span 每层 cost
- **P-II 自然语言 Signals**：基于 span 树的确定性运行监测
- **P-III Agent 自查运行档案**：只读 span 查询工具
- **P-IV Eval Datasets（评估数据集）飞轮** + 真实 input/output 采样 + 测试挂钩
- **Web UI**：运行档案 / Signals / 评估数据集可视化 tab + 正式 API 文档
- 修复 P-III span 查询工具测试的类型问题

## 架构说明

- server：Goal 状态层 + 运行档案 P-I~P-IV + 多维评估数据底座
- electron：引入 Goal 状态层控制平面
