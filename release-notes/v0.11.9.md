# Proma v0.11.9

> 对比基准：v0.11.8

本次版本在 server 侧引入 **运行档案层（P-I）**，并修正日历同步命名残留。

## Server：运行档案层（P-I）

- 引入 **trace_id 闭环**：Agent 运行全程串联 trace 上下文
- 新增 **Runtime Span**：记录运行关键步骤，为后续监测/Signals/评估奠定数据底座
- 修复工具调用产生**悬空 span** 的数据完整性问题，确保 span 树完整闭合

## 修复：日历同步命名残留

- 替换 PAA 残留名称为 **Proma MIT**，修正日历权限提示文案

## 架构说明

- server：运行档案层（trace_id 闭环 + Runtime Span）
- electron：日历同步文案与品牌名称修正

## 开发与文档

- 版本更新 — `@proma/electron` 从 `0.11.8` 升级到 `0.11.9`
