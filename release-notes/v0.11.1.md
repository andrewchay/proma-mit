# Proma v0.11.1

> 对比基准：v0.11.0

本次版本将个人助理项目（~/LLM/PAA）中的「项目管理」与「日程管家」两大工作模块迁入 Proma 工作模块（左侧栏底部），配置能力一并接入，全部代码沿用本地 SQLite / JSONL 存储，不依赖外部服务。

## 工作模块：项目管理（`projects`）

- **项目/任务/子任务 CRUD**：本地 SQLite（sql.js，`~/.proma/projects/paa.db`，写后落盘）
- **看板与进度**：按状态聚合的 Kanban 视图、项目进度计算
- **会议纪要导入与 AI 提取**：粘贴/导入会议纪要 → LLM 自动提取任务草稿（草稿确认/驳回）
- **钉钉文档拉取**：从钉钉云文档拉取内容并提取任务
- **项目摘要与周报**：一键生成 Markdown 摘要，可发送到飞书群 / 钉钉
- **外部同步**：飞书 / 钉钉 Todo 双向同步、任务状态轮询、自动风险评估与风险报告
- **Brief 回执**：核心任务（高优先级/高风险）自动生成回执表单（内嵌 H5 回调服务，默认端口 8765）
- **负责人选择器**：飞书/钉钉通讯录搜索，选中后自动写入用户映射

## 工作模块：日程管家（`calendar`）

- **日程事件/任务 CRUD**：JSONL 存储（`~/.proma/calendar/`），支持重复事件、分类、标签、提醒
- **月视图日历 + 任务看板**：左侧月历网格，右侧任务看板与选中日期详情
- **自然语言创建**：输入自然语言自动解析为结构化日程（时间/地点/类别/重复规则）
- **冲突检测**：创建/更新时自动检测时间冲突并提示
- **多日历源同步**：Google / Apple / Outlook / 本地日历源管理、双向同步、冲突解决策略、同步日志；macOS 支持 EventKit 系统日历桥接（`read-calendar.swift`）
- **智能提醒**：日程冲突、Deadline 分级提醒（24h / 15min / 逾期）、去重

## 配置能力

- 设置面板新增「日历同步」Tab（`CalendarSyncSettings`）
- `settings.json` 新增 `feishuTodo` / `dingtalkTodo` / `briefCallback` 配置字段
- 外部同步复用已有飞书/钉钉 Bot Hub 配置与 `settings-service` 变更监听（新增 `onSettingsChange`）

## 架构说明

- shared 层新增 `SCHEDULE / CALENDAR_SYNC / PROJECT_IPC_CHANNELS` 常量与类型（`packages/shared/src/types/work-module.ts`）
- 主进程新增 `work-module-ipc-handlers.ts` 统一注册三组 IPC，含 Todo Provider 初始化、轮询与自动同步
- Preload 暴露 `electronAPI.paa.schedule / calendarSync / project` 三组 API
- 启动时初始化项目管理数据库与 Brief 回调服务，退出时持久化并关闭数据库
- 渲染层：`components/projects/ProjectView.tsx`、`components/calendar/`（ScheduleView / EventCreatePanel / CalendarSyncView / CalendarModuleView）
- 新增依赖：`sql.js`（+ `@types/sql.js`）

## 升级建议

- 项目管理数据位于 `~/.proma/projects/paa.db`，日程数据位于 `~/.proma/calendar/`，可直接备份/迁移
- 首次进入项目管理会自动初始化数据库；使用飞书/钉钉待办同步前需在「远程连接」配置对应 Bot
