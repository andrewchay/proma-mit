# Proma v0.11.8

> 对比基准：v0.11.7

本次版本修复 **macOS 灵动岛**状态同步问题。

## 灵动岛状态修复

- 修复权限 / AskUser / 计划审批等响应后未同步 `resolved` 事件到 `agentEventBus`，导致灵动岛状态卡在黄色的问题
- 响应处理后正确推送事件，灵动岛状态即时更新

## 架构说明

- 主进程：灵动岛事件总线同步逻辑补全

## 开发与文档

- 版本更新 — `@proma/electron` 从 `0.11.7` 升级到 `0.11.8`
