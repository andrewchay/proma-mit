# Gravitas v0.11.22

> 对比基准：v0.11.21

本次版本新增 **collaboration 协作子会话父子树面板**，侧栏即可追踪子任务树。

## Collaboration 父子树面板

- 侧栏新增 **collaboration 父子树面板**：可视化展示协作子会话（子代理）的父子依赖关系
- 便于在长时间多子任务并行时，清晰追踪每个子任务的执行状态与归属

## 架构说明

- 渲染层：侧栏 collaboration 父子树视图
- agent runtime：协作子会话树结构对齐

## 开发与文档

- 版本更新 — `@gravitas/electron` 从 `0.11.21` 升级到 `0.11.22`
