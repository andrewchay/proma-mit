# Proma v0.11.14

> 对比基准：v0.11.13

本次版本完成 Goal **E1-E5：增强目标体验与证据语义化**。

## Goal E1-E5：增强目标体验与证据语义化

- 增强目标体验：目的地展示、阶段引导、进度反馈更友好
- 证据语义化：运行证据（Evidence）具备更明确的结构化语义，可作为决策与审计依据

## 架构说明

- server：Goal 证据语义化
- electron：目标体验 UI 增强

## 开发与文档

- 版本更新 — `@proma/electron` 从 `0.11.13` 升级到 `0.11.14`
