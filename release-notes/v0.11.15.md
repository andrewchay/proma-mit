# Proma v0.11.15

> 对比基准：v0.11.14

本次版本完成 Goal **E6-E9：证据管理、配额接入与路由扩展**。

## Goal E6-E9：证据管理 / 配额接入 / 路由扩展

- **证据管理**：运行证据统一管理，支持检索与关联
- **配额接入**：配额机制与各 Goal 执行路径完整接入
- **路由扩展**：Goal 执行路由支持更多目标类型与扩展场景

## 架构说明

- server：Goal 证据管理 / 配额接入 / 路由扩展
- electron：Goal 相关 UI 联动

## 开发与文档

- 版本更新 — `@proma/electron` 从 `0.11.14` 升级到 `0.11.15`
